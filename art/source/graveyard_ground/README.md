# Земля кладбища

17.10.2026. Первый production-ассет окружения; внешний вид принят пользователем.

- Референс: принятый `art/concepts/graveyard/env_ground.svg`.
- `master.svg`: вручную написанный SVG, размер импорта 128×128, viewBox 256×256.
  Такой размер соответствует текущему контракту `BattlefieldCell` и не требует
  увеличенной runtime-текстуры. После импорта RGBA8 без mipmaps — 64 KiB.
- Непрозрачная база `#303838`; почва `#343e3b`, мох `#454d43`,
  камешки `#505755`, короткие отметки `#535b53`.
- Кромки имеют одинаковый базовый цвет; нет stroke по периметру,
  полупрозрачного края, фильтров, градиентов и обводки клетки.
- Детали внутри холста, оттенки немного спокойнее concept-версии.
  Все 54 клетки в превью используют один тайл без поворотов и вариаций.

Это плоская земля: Skeleton2D, части и анимации ей не требуются.
Исходник сохраняет `.gdignore`; runtime-копия `assets/environment/graveyard/ground.svg`
импортирована и подключена через `resources/biomes/graveyard_battlefield.tres` в общем
этапе окружения от 17.10.2026. Принятое изображение при копировании не изменялось.

Сборка превью: `python art/previews/graveyard_ground/build_preview.py`.
Результат: `build/web/preview/graveyard-ground/index.html`.
Превью использует существующие SVG бойцов, дороги, постаментов, портала и башни.
Персонажи статичны, их runtime-шейдеры и VFX в этом просмотре не воспроизводятся.
