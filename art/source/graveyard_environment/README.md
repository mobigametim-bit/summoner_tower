# Окружение кладбища

17.10.2026. Пользователь отдельно разрешил дорогу и интеграцию всего принятого
окружения одним этапом, без промежуточной приёмки каждого объекта.

Собственные SVG исходники:

- Земля — принятый `art/source/graveyard_ground/master.svg`.
- Дорога — новый `art/source/graveyard_road/master.svg`.
- Постамент, портал и 10 декораций — принятые `art/concepts/graveyard/env_*.svg`.
  Их geometry сохранена; canvas не обрезается, меняется только размер импорта.

`prepare_assets.py` сохраняет runtime-копии в `assets/environment/graveyard/`:
земля/портал 128×128, дорога 64×64, постамент 140×140, декорации 64×64.
Четырнадцать общих текстур без mipmaps: расчёт RGBA8 по размерам — 389696 байт
(около 0.37 MiB). Это оценка пиксельных данных, не замер общей GPU-памяти или FPS.

Оформление находится в `resources/biomes/graveyard_battlefield.tres`.
Размер сетки, маршруты, слоты, шанс/масштаб/вращение декораций и логика волн не менялись.
Портал использует прежние два CPUParticles2D с мятным цветом; новые emitters не добавлены.

Декорации: мёртвое дерево, надгробие, крест, склеп, ограда, останки, свечи,
фонарь душ, увядшие цветы, гроб. Выбор равновероятный: 10% на тип при появлении
декорации; общий шанс на свободной клетке 40%. Масштаб 0.9–1.5, вращение ±0.2 рад.

`scenes/ui/GraveyardMenuBackdrop.tscn` — отдельная редактируемая композиция,
собранная через Godot MCP на основе существующего меню и новых текстур окружения.
Обычный бой кладбища ждёт своих врагов и босса. Его оформление уже привязано к биому;
для проверки настоящего боя со старой армией есть development-сцена
`scenes/debug/GraveyardEnvironmentReview.tscn`, исключённая из production export.
