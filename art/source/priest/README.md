# Жрец света — SVG art gate

Пять принятых концептов перенесены в отдельные rigid cutout SVG-части.
Art принят пользователем. Созданы rigid rig, idle/cast/spawn и отдельное VFX-превью,
которые приняты пользователем. Жрец подключён к бою и принят 18.10.2026.
[Игровая проверка](http://127.0.0.1:4175/preview/priest-gameplay/).
[Принятый art](../../../docs/done/PRIEST_ART_REVIEW.md),
[отчёт анимационного gate](../../../docs/done/PRIEST_ANIMATION_REVIEW.md).
[План и принятый баланс](../../../docs/PRIEST_PRODUCTION_PLAN.md).

Source: собственный SVG-код в `build_art.py`. Новые формы сохраняют силуэт, палитру
и экипировку принятого концепта. Добавлены скрытые продолжения плеч, запястий и бёдер.
Никаких raster embeds, image generators, чужих sprites, mesh или trimming.

`master.svg` — Lv1; `master_lv2.svg`…`master_lv5.svg` — другие уровни, собранные
из тех же групп, что сохранены в `parts/`. Повторяющиеся текстуры переиспользуются
между уровнями; отсутствие нимба на Lv1–4 выражено null в manifest.
Получилось 26 уникальных текстур частей вместо 40 отдельных текстур для всех уровней.
При импорте 256×256 RGBA8 это примерно 6.5 MiB без mipmaps; экземпляры делят текстуры.

Восемь частей: halo, back_arm (вместе с книгой и кистью), leg_left, leg_right,
body, staff, front_arm, head. Нимб появится на Lv5 без дополнительной кости.
Созданы восемь Bone2D вместе с Root. Книга следует руке одним жёстким фрагментом.

Полный холст 256×256, actor_origin=(128,128), baseline ступней около y=239.
Точные pivots/слои/варианты записаны в `rig_manifest.json`. В игре части прикреплены
к костям, а master используется для review/static fallback/drag preview.
Координаты солнечного навершия ReleasePoint — (211,92) на исходном холсте.

```powershell
python art/source/priest/build_art.py
```

Команда собирает source SVG/manifest и изолированную копию статического превью в
`build/web/preview/priest-art/`. Действующая игра и gameplay Resources не изменяются.
Просмотр через существующий HTTP-сервер:
<http://127.0.0.1:4175/preview/priest-art/>.

В `review.html`: все пять уровней, сравнение с концептом, масштабы 54/76/100/140/180 px,
постаменты, части/pivots, зеркало и неподвижные примерки крайних поз.
Перекрытия и pivots проверены в принятых idle/cast/spawn. Во время игровой интеграции
проверены выпуск из посоха и поведение при слиянии/продаже. Rig остаётся rigid cutout.
