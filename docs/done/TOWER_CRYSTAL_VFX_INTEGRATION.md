# Башня — внедрение частиц кристалла

09.10.2026. Визуальное превью и интеграция приняты пользователем. Выполненные проверки сохранены ниже.

## Результат

В игровой башне работают принятые голубые частицы: 24 в покое и 40 при тапе. Сохранены последние принятые настройки: удвоенный радиус, увеличенные отдельные частицы, прежняя длительность. Эффект не меняет ману, стоимость призыва, урон, здоровье или логику волн.

Компонент `scenes/vfx/TowerCrystalEnergy.tscn` включён в `TowerVisual.tscn` под `CrystalPivot` со смещением (0, −28). Он автоматически следует исходной анимации кристалла. Существующий `TowerVisual.show_tap()` запускает всплеск; существующее событие нажатия башни и призыв не изменены.

При паузе настроек частицы и ореол останавливаются вместе с боем. При разрушении фоновое свечение выключается, активный всплеск удаляется. После смены сцены компоненты освобождаются; при рестарте создаётся новая башня. Static fallback остаётся доступен; дочерний эффект скрывается вместе с TowerVisual.

## Ресурсы

- `scenes/vfx/TowerCrystalEnergy.tscn`, `TowerEnergyTapBurst.tscn`;
- `scripts/visuals/tower_crystal_energy.gd`;
- `resources/vfx/tower_energy/`;
- `assets/vfx/energy_spark.svg` и настройки его импорта.

Перенос существующих ресурсов выполнен через Godot MCP с обновлением ссылок и сохранением UID. Runtime-компонент не зависит от debug-каталогов. Сцена прежнего превью использует тот же компонент, чтобы параметры не расходились.

## Проверки

- MCP lint после окончательных изменений: 72 сцены, 85 скриптов, 0 ошибок и предупреждений.
- Native реальный gameplay через HudGameplayReview: тап создаёт одного бойца и включает всплеск; фоновых частиц 24; пауза замораживает эффект; уничтожение башни выключает фон и активный всплеск. Тест использовал изолированный прогресс.
- Production Web и development gameplay preview экспортированы через MCP, главная сцена восстановлена в main_menu.tscn.
- Edge Web: touch-призыв, мана 100 → 80, просмотр всплеска в настоящем поле; пауза и выход в меню; запуск production игры. Консоль без ошибок. Просмотрены браузерные скриншоты.
- Физический телефон и длительные нагрузочные волны не проверялись в рамках этой правки.
