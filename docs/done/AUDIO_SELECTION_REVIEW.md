## Прослушивание

Открыть [страницу подборки](http://127.0.0.1:4175/preview/audio/). Локальный сервер обслуживает `build/web/` на порту 4175. Страница и аудиофайлы находятся в `build/web/preview/audio/`; архивы и оригинальные страницы источников — в `.tools/audio-source/`. Эти временные каталоги исключены из Git.

В подборке 26 SFX-кандидатов на 16 согласованных событий и четыре музыкальных кандидата. Общий размер выбранных оригиналов — около 10,06 MiB. Нажатие нового эффекта прекращает предыдущий; музыка может продолжать играть для сравнения сочетания. Одновременно воспроизводится одна музыкальная тема. Есть отдельные регуляторы громкости, повтор музыки и остановка всех проигрывателей. Автоматического старта звука нет.

Исходные файлы сохранены без изменения. Громкость разных исходников различается; финальная нормализация, обрезка, ограничение одновременных голосов и сведение должны выполняться после выбора, при проверке настоящего боя.

## Покрытие событий

1. Нажатия UI — два коротких варианта.
2. Призыв — магическое появление.
3. Merge — магический акцент или короткая фанфара.
4. Продажа — возврат энергии.
5. Выстрел лучника — звук лука из Battle Sound Effects.
6. Огненный маг — два огненных заклинания.
7. Ледяной маг — два ледяных эффекта.
8. Попадания — отдельные кандидаты для стрелы, огня и льда.
9. Смерть врага — короткая реакция существа или падение без голоса.
10. Урон башне — каменный удар.
11. Падение башни — рассыпание/энергия или каменные обломки.
12. Возрождение — восстанавливающая магия.
13. BOSS — короткий музыкальный удар или колокольный акцент.
14. Карточка улучшения — подтверждение выбора.
15. Постоянное улучшение — магическое усиление.
16. Кристаллы душ — два звонких варианта.

Предложения по назначению сделаны на основе описаний авторов и категорий исходников. Техническое воспроизведение проверено; художественная оценка и раздражительность при повторении требуют ручного прослушивания. Для окружения, постоянного свечения посохов и каждого выхода из портала новые звуки на этом этапе не предлагаются.

## Проверки

В Microsoft Edge через Playwright:

- Все 30 выбранных файлов успешно загружены и декодированы Web Audio; содержат ненулевой аудиосигнал.
- Измерены длительность, число каналов, peak и RMS. Значение sample rate в диагностике — частота браузерного AudioContext после декодирования, а не утверждение о частоте исходного файла.
- Проверены кнопки SFX, запуск и переключение музыкальных проигрывателей, отключение повтора, регулятор музыки и остановка всех проигрывателей.
- Нет ошибок JavaScript или загрузки ресурсов в итоговом прогоне.
- При viewport 390 × 844 нет горизонтального переполнения; расположение страницы просмотрено на скриншоте.

Диагностика: `build/web/preview/audio/checks.json`. Скрипт проверки: `.tools/check_audio_preview.cjs`. Godot runtime и экспорт не запускались: игра на этом этапе не изменялась, проверялся отдельный HTML-preview. На физическом телефоне и в других браузерах проверка не выполнялась.

## Ручная приёмка

1. Выбрать A/B для меню и A/B для боя. Оценить полный повтор выбранной музыки.
2. Прослушать 16 групп; указать неудачные события и выбрать варианты там, где их два.
3. Оценить эффекты поверх выбранной боевой музыки. Особое внимание — лучнику, огню, льду, попаданиям и смерти: они будут повторяться часто.
4. После выбора согласовать внедрение. Проверка ограничений голосов, микширования, browser audio unlock, сохранения громкости и поведения при паузе/смене сцен относится к следующему согласованному этапу.
