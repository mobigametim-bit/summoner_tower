# Обучение с архимагом Бородацием

19.10.2026. Сценарий, art/UI и игровая интеграция приняты пользователем.
Отчёт о реализации и проверках: [TUTORIAL_GAMEPLAY_REVIEW.md](TUTORIAL_GAMEPLAY_REVIEW.md).

## Подтверждённые решения

- Наставник — архимаг Бородаций, приземистый маг с длинной светлой бородой.
  Короткие реплики, добродушное ворчание и юмор из согласованного сценария.
- Первые два успешных учебных призыва гарантированно дают лучников;
  оплачиваются по обычным правилам, затем возвращается случайный призыв.
- После замечания пользователя первая учебная карта зафиксирована: seed 146,
  6×9, 12 постаментов и один верхний портал. Перенос ведёт в клетку (2,2).
  Для принятой горизонтальной компоновки отдельная фиксированная карта: 9×6,
  seed 0; свободный постамент выбирается ближе всего к той же клетке.
  После первого босса и в последующих обычных забегах генерация снова случайна.
- Обучение предлагается всем, кто его ещё не проходил, включая существующие
  сохранения. Купленные улучшения, валюта и открытые биомы сохраняются.
- Сначала art/UI preview и ручная приёмка, затем игровая интеграция.
- Обязательная часть: меню → поле/цель → призыв → движение/радиус → второй призыв
  → слияние → первый бой/мана. Остальное объясняется при первом соответствующем событии.
- Продажа, просмотр рекламы, проигрыш и метапокупка не являются обязательными действиями.
- По решению пользователя кнопки пропуска нет. Повтор доступен из настроек;
  этапы сохраняются. Основное обучение — примерно минута.
- Критические объяснения на паузе; одна подсказка за раз; мгновенное отображение текста.
- Окончание всех волн биома на волне 25 — победа; условные подсказки Жреца,
  кладбища и способностей появляются по мере встречи.

## Завершённые этапы

`art/concepts/tutorial/borodacius.svg` — вручную написанный SVG-концепт наставника.
`art/concepts/tutorial/index.html` — отдельный браузерный макет с текущими игровыми
экранами и примерами приветствия, призыва, слияния и перехода после босса.
Макет сохраняется как исходный визуальный ориентир; обучение реализовано в Godot.

На принятом этапе превью проверялись: внешность/борода, размер портрета, читаемость реплик на телефоне,
выделение цели и удобство кнопок. Затем реализованы подробный сценарий в данных,
Godot UI-сцена, управление шагами и сохранение; игровые проверки выполнены.

Баланс, обычный призыв, сохранения и сцены игры на этапе превью не изменялись.

## Порядок подсказок

Полный сценарий обсуждён в чате. Обязательные действия и условные события
разделены, чтобы не заставлять игрока проигрывать, продавать бойцов или смотреть рекламу.

| Событие | Содержание / действие |
| --- | --- |
| Первый вход в меню без отметки об обучении | Бородаций, кнопка начала, без пропуска |
| Старт учебного забега | Кнопка Play, лес |
| Появление поля | Портал → дорога → башня, цель защиты |
| Начало боя | Здоровье башни, смысл нуля |
| Первый призыв | Нажать башню, заплатить обычную цену, получить лучника |
| Первый боец | Автоматические атаки, размещение на постаментах |
| Мана и цена | Запас маны, удорожание успешных призывов |
| Первое перемещение | Перенос на свободный постамент, радиус атаки |
| Второй призыв | Второй гарантированный лучник за обычную цену |
| Первое слияние | Одинаковые тип и уровень; два исходных бойца → один нового уровня |
| Наведение на пару | Текущий и будущий радиусы одновременно |
| После слияния | Пять уровней, зелёный/оранжевый/красный/синий/фиолетовый |
| Первый разрешённый враг | Мана за убитого или дошедшего; дошедший всё ещё наносит урон |
| Следующий случайный тип | После первых двух призывов снова работает обычная случайность |
| Первый огненный маг | Урон и развитие горения/области |
| Первый морозный маг | Замедление, развитие заморозки |
| Несовместимая пара | Swap вместо merge |
| Заполненные постаменты | Слияние, перестановка и добровольная продажа |
| Перенос на башню | Ручной возврат 50% реальных вложений; бонусы/текущую сумму показывать по факту |
| Первый Lv3 | Меняется характер атак |
| Первый Lv5 | Автоматическая способность |
| Пара Lv5 | Максимум, только обмен местами |
| Усиленный враг | Цвет, экипировка и уровни |
| Первое применение способности врага | Коротко объяснить конкретный видимый эффект, без предварительной лекции |
| Настройки в бою | Пауза, громкость, язык; выход прекращает забег |
| Первая боссовая волна | Каждая пятая, босс плюс обычные враги |
| Босс погиб раньше свиты волны | Нужно завершить всю волну |
| Первые карточки | Одна награда, временные усиления и разовые подарки |
| Цвета карточек | Уровень/сила варианта |
| Повторная карточка | Бонусы накапливаются, смотреть на числа |
| Переброс | Добровольный просмотр, один успешный рекламный переброс за боссовую волну |
| Перед выбором после волны 5 | Предупредить о смене карты, автопродаже 80%, потере остатка маны |
| Переход после волн 10/15 | Короткое уведомление о 60%/40%; далее 40% |
| Первый подарок бойца | За бесплатного бойца возврат 0 |
| Первое падение башни | Возрождение +50 ОЗ за просмотр, один раз за забег, добровольно |
| Первые результаты | Кристаллы сохраняются, добровольное удвоение награды |
| Возврат с наградой | Показать вход в метаулучшения |
| Первое посещение меты | Постоянные бонусы и независимое удвоение цен веток |
| Первая метапокупка | Бонус действует со следующего забега |
| Первая победа на волне 25 | Завершение биома, открытие кладбища |
| Меню после разблокировки | Стрелки биомов, общие прогресс и валюта |
| Первый Жрец | Метка света, постоянное расширение призыва обоих биомов; башню не лечит |
| Первые останки кладбища | Переносятся между волнами; некромант собирает голема из двух |

Для текстов с ценами, процентами возврата, наградой возрождения и названиями
использовать фактические данные игры и локализацию, чтобы обучение не расходилось с балансом.
