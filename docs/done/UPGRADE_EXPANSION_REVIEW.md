# Расширение карточек и метаулучшений

14.10.2026. Реализовано по запросу пользователя; ожидается ручная приёмка. Commit/push этого этапа не выполнялись. Предыдущие незавершённые изменения рабочего дерева сохранены.

Пул содержит 20 видов: прежние 6 и новые 14. «Перезарядка» исключена. Выбор одного улучшения из трёх сохраняется; купленное метаулучшение «Расширенный выбор» даёт четыре варианта.

«Выгодная продажа» меняет ручной возврат. По последующему запросу от14.10.2026 автоматическая продажа армии после волн5/10/15/20 возвращает80/60/40/30%, далее30%. Бесплатный боец из карточки возвращает0. Реализация и новые проверки: [TOWER_SUMMON_ECONOMY_REVIEW.md](TOWER_SUMMON_ECONOMY_REVIEW.md).

Последующее уточнение того же дня: старый остаток маны при смене карты сгорает, бюджет становится равен возврату за армию. «Запас маны» начисляет100 после смены карты, чтобы сохранить действие выбранной награды.

Бойцы Lv5 выдаются после продажи старой армии, генерации поля и перепривязки слотов. Выдача не расходует ману и не увеличивает цену призыва. paid_mana=0; бойца можно убрать ручной продажей с возвратом0. Это реализация согласованной бесплатной награды, без новой системы инвентаря. Каждая повторно выбранная такая карточка выдаёт одного бойца на очередной новой карте.

Прежние карточки Rapid Fire, Power, Mana Flow, Tower Armor, Frost Power, Cheap Summons сохранены. Процентные прибавки повторных карточек перемножаются, лечение/заморозка/пункты продажи складываются. Все бонусы сбрасываются при новом забеге.

## Метаулучшения

Уточнение от14.10.2026: подсказки меты заменены на описание эффектов, добавлен отдельный рекламный переброс один успешный раз за боссовую волну, бесплатный переброс сохранён. Текущая реализация и проверки: [UPGRADE_TOOLTIPS_REWARDED_REROLL_REVIEW.md](UPGRADE_TOOLTIPS_REWARDED_REROLL_REVIEW.md).

Первые четыре улучшения и их индексы сохранены. Новые семь:

| Улучшение | За уровень | Предел |
|---|---|---|
| Боевая подготовка | +2% частоты обычных атак | Lv10, +20% |
| Зоркость | +2% радиуса атаки | Lv5, +10% |
| Экономный призыв | −2% стоимости призыва | Lv10, −20% |
| Регенерация | +1 HP после волны | Lv5, +5 HP |
| Знание способностей | −2% кулдауна способностей Lv5 | Lv5, −10% |
| Удачный выбор | Один бесплатный переброс за забег | Одна покупка |
| Расширенный выбор | Четыре карточки вместо трёх | Одна покупка |

Цена сохраняет шаг25 кристаллов: 25/50/75… за уровни одного улучшения. По последующему запросу «Удачный выбор» и «Расширенный выбор» стоят125 кристаллов каждый. Постоянные проценты складываются от базового значения; скидка меты умножается на скидку Cheap Summons. Например, максимальная мета −20% и одна Cheap Summons дают0,8×0,85 от текущей базовой цены, с округлением вверх и минимумом1.

Экран меты содержит постоянные узлы всех 11 карточек и ScrollContainer. Кошелёк и кнопка возврата остаются над списком. Выбор после босса содержит четыре постоянных Button и кнопку переброса, лишние варианты скрываются. Переброс расходуется до обновления предложения, повторное нажатие не даёт дополнительного переброса.

## Реализация

- Написана вручную 21 новая SVG-иконка96×96 в assets/upgrades/: 14 для карточек и7 для метаулучшений. Использованы простые paths/shapes, без image generators и стороннего art. У всех карточек есть Texture2D, русские и английские тексты.
- Resource карточек бойцов называется upgrade_archer_lv5.tres / upgrade_mage_lv5.tres / upgrade_frost_mage_lv5.tres; UnitStats остаются archer_lv5.tres / mage_lv5.tres / frost_mage_lv5.tres. Конфликт имён, найденный в ходе реализации, исправлен; исходные эффективные значения восстановлены из сохранённых в редакторе Resources, UID сохранены. Проверены damage/range/interval/abilities всех трёх Lv5 после восстановления.
- RunBonuses централизует расчёты. CombatUnit использует эффективные radius/cooldown; drag и preview будущего merge используют тот же радиус. Снаряд получает снимок UnitStats, не меняя общий Resource.
- Мощь игрока учитывает эффективные радиус, урон специализации, частоту атак, горение, заморозку и кулдаун способности. Для увеличенного радиуса области существующий area_power_multiplier умножается на коэффициент расширения; геометрия дороги/постаментов в расчёт не добавлялась.
- Regen вызывается по wave_completed, с защитой от повторной обработки номера волны. Лечение не оживляет разрушенную башню и не превышает максимум.
- Формат сохранения2: 11 уровней с индивидуальными пределами. Version1 с четырьмя уровнями загружается с добавлением семи нулей; кристаллы и старые уровни сохраняются. Более новая версия не перезаписывается. Покупка при ошибке записи откатывается.
- Сцены/узлы/сигналы изменены через Godot MCP; редактор4.7.2, Compatibility. Debug-сцены исключены из обычного Web export.
