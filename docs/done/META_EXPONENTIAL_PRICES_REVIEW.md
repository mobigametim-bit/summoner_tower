# Удвоение цен метаулучшений

Дата: 18.10.2026. Статус: реализовано, проверено и принято пользователем.

## Правила

- Каждая ветка считает цену независимо: `25 × 2^текущий_уровень`.
- Последовательность до Lv10: 25, 50, 100, 200, 400, 800, 1600, 3200, 6400, 12800.
- «Удачный выбор» и «Расширенный выбор»: по 250 кристаллов, по одному уровню.
- Эффекты, пределы уровней, купленные улучшения и баланс кристаллов не меняются.
- На максимальном уровне покупка недоступна.

| Ветки | Количество | Цена полной прокачки одной ветки |
| --- | ---: | ---: |
| Здоровье башни, урон бойцов, приток маны, стартовая мана, боевая подготовка, экономный призыв | 6 | 25575 |
| Зоркость, регенерация, знание способностей | 3 | 775 |
| Удачный выбор, расширенный выбор | 2 | 250 |

Всего: **156275 кристаллов**, 77 покупок.

## Изменения

- `scripts/data/meta_upgrade_config.gd`: формула цены и множитель специальных улучшений.
- `tests/support/feature_11_test_scene.gd`: актуализированы ожидания стоимости первых четырёх веток.
- `tests/support/meta_price_checks.gd`: целевая проверка цен и покупок всех 11 веток.

## Проверки

- Godot MCP: проект `C:/Gamedis/summoner-tower`, Godot 4.7.2, Compatibility.
- В изолированной сессии без записи на диск проверены все 77 покупок через
  настоящий `SessionProgress.try_buy`: цена, отказ при нехватке одного кристалла,
  точное списание, рост уровня, блокировка после капа и общая стоимость.
- В настоящем экране меты проверена покупка Lv10 за 12800: баланс 20000 → 7200,
  уровень 9 → 10, карточка блокируется. Цена отображается как `12.8K` и помещается.
- Ошибок runtime через Godot MCP нет.
- Release Web export, мобильный viewport 390 × 844: меню → улучшения,
  просмотр начала/конца списка свайпами. Цены 25 и 250 отображаются корректно;
  ошибок browser console и JavaScript нет.
- Старый общий сценарий фичи 11 целиком не прогонялся: выполнена целевая проверка экономики.
- Пользовательское сохранение не изменялось тестами.

## Ручная приёмка

Сборка: http://127.0.0.1:4175/preview/meta-prices/

1. Проверить новую цену следующего уровня с текущим прогрессом в редакторе.
2. При покупке убедиться, что цена этой ветки удвоилась, соседних — сохранилась.
3. В конце списка проверить цены двух одноуровневых улучшений: по 250.

Браузерная сборка использует сохранение своего origin; native-прогресс и IndexedDB
браузера независимы. На реальном телефоне эта сборка ещё не проверялась.
Ручная приёмка получена 18.10.2026. Отчёт перенесён в `docs/done/`.
