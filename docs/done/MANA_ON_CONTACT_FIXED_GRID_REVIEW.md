# Мана за дошедших врагов и фиксированная сетка

16.10.2026. Реализовано по прямому запросу пользователя и принято им вручную.

## Поведение

- На присланном скриншоте 6 столбцов и 9 рядов: всего 54 клетки.
- В `battlefield_config.tres` установлен `column_range = Vector2i(6, 6)`.
  При текущем игровом прямоугольнике клетка равна 120×120 логических px,
  поле — 720×1080; масштабирование на устройстве сохраняет квадратные клетки.
  Размер сохраняется при новом забеге и регенерации после босса.
- Постаменты остаются случайными 10–15; порталы 1–3 с шансами 50/30/20%; остальные
  настройки маршрута и декораций сохраняются.
- Мана за достижение башни равна награде за убийство того же типа и уровня.
  Работают текущие бонусы дохода и накопление дробного остатка.
- Начисление происходит до урона башне, включая смертельный удар и окно возрождения.
  Пополнение использует существующие всплывающую награду и анимацию счётчика.
- Дошедший враг наносит прежний урон; не увеличивает число убийств/убитых боссов.
  Защита `_resolved` и исключение из `_active` сохраняют однократность награды/урона.

## Проверки

Godot MCP подключён к `C:/Gamedis/summoner-tower`, Godot 4.7.2, Compatibility.
Изолированные данные прогресса через `SessionProgress.use_test_save()`.

- Целевой `tests/support/tower_contact_mana_checks.gd`: гоблин Lv1 (+3), орк Lv3 (+20),
  голем Lv2 (+16), босс Lv5 (+480) при достижении башни; исходный урон и статистика.
- Повторный contact, урон уже разрешённому врагу и старый callback WaveManager
  не начисляют ману и урон повторно. Обычное убийство гоблина Lv2 по-прежнему даёт +6.
- Четыре контакта гоблинов с бонусом дохода +20% дают суммарно 14 маны;
  дробная часть не теряется при каждом событии.
- Смертельный контакт: +3 маны, затем ОЗ=0 и REVIVE_OFFER; повторного начисления нет.
- Настоящая регенерация карты с 1/2/3 порталами: каждый раз 6×9, 10–15 постаментов,
  маршруты проходят `BattlefieldGenerator.is_valid()`.
- Дополнительно обычный враг доведён по существующему маршруту до башни через physics:
  мана 55→58, ОЗ 100→90. Сетка и HUD просмотрены в runtime.
- После синхронизации открытого скрипта редактора и файлов проверки прошли;
  после успешного прогона новых runtime errors нет. Пользовательские сцены не менялись.
- Release Web export через MCP успешен; branding упакован штатным `tools/package_web.py`.
- Edge, CSS 390×844/DPR3: естественное достижение башни без армии дало 118 маны
  при оставшихся 40 ОЗ на второй волне (старт 100 маны / 100 ОЗ).
  Затем touch-призыв создал бойцов; при дальнейшем падении башни открылось окно
  возрождения. Скриншоты просмотрены, поле 6×9 и нижний HUD читаемы.
  Ошибок Godot/JavaScript и HTTP нет; внутренний кадр 585×1266.
  Реальный телефон и температура устройства в этой проверке не оценивались.

## Ручная приёмка

1. Пропустить врага к башне: ОЗ уменьшаются, мана увеличивается и появляется +N.
2. Проверить награду врагов разных уровней и всплывающее окно при разрушении башни.
3. Начать новый забег и пройти босса: сетка каждый раз остаётся 6×9.

Локальная Web-сборка: <http://127.0.0.1:4175/?v=contact-mana-grid6>.
