# Название биома в заголовке главного меню

17.10.2026. Реализовано, проверено и принято пользователем.

Вместо SUMMONER TOWER главный заголовок показывает имя выбранного биома:
«ЛЕС» / «КЛАДБИЩЕ» или FOREST / GRAVEYARD. Текст берётся из `BiomeDefinition.title`
и обновляется при переключении биома и языка. Название игры на загрузке сохранено.
Стрелки остаются у краёв на высоте кошелька, отдельная строка названия не возвращается.

Изменён текст существующего Label через Godot MCP; привязка к данным находится
в `main_menu.gd`. Добавлено поле заголовка в snapshot development-просмотра.

Проверено: Godot 4.7.2, Compatibility; lint двух скриптов без замечаний,
оба биома и RU/EN, runtime errors отсутствуют. Release Web exports собраны;
основная сцена возвращена к `scenes/main_menu.tscn`.
В Edge (390×844/DPR3, 768×1024, 1400×900) проверены оба заголовка, touch-переключение,
выравнивание стрелок, сохранение выбора после reload и запуск леса.
Просмотрены мобильные изображения обоих биомов, переполнения нет; ошибок JS/Godot/HTTP нет.
Прогресс изолирован, физические устройства не проверялись.

Ручная проверка на этом компьютере:
<http://127.0.0.1:4175/preview/biomes/?v=biome-title>.
Нажать **Open graveyard · TEST**, переключиться вправо и обратно и проверить заголовок.

Принятая раскладка стрелок опубликована отдельным commit `7e97f9a`;
замена заголовка принята и передаётся в репозиторий и публичную Web-сборку.
