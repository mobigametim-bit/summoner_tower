## Реализация

- 35 новых SVG textures на полных холстах 256×256: 10 гоблина, 11 орка, 14 голема. Все формы взяты из принятого собственного SVG-превью.
- `art/source/<enemy>/equipment/` — production parts; базовые masters и старые parts сохранены.
- `art/source/enemy_equipment_manifest.json` — позиции/pivots, node paths, z-order, texture tables; `build_runtime_parts.py` в каталоге превью воспроизводит выделение новых частей.
- `scripts/visuals/enemy_equipment_part.gd` — выбор texture/visibility и цвета акцентов. На один узел приходится ровно пять записей; `null` означает отсутствие детали.
- `art/source/equipment_accent.gdshader` — только акценты новых деталей. Цветовые материалы локальны экземпляру врага и общие для его деталей.
- Сцены `GoblinVisual`, `OrcVisual`, `GolemVisual` изменены через Godot MCP. Кости и исходные анимационные tracks сохранены; повторное сохранение Godot незначительно округлило несколько float-значений в GolemVisual.
- Поиск ссылок на Sprite2D выполняется один раз при готовности visual, не каждый кадр. Переключение экипировки выполняется при назначении сложности.

Сохраняются 8 / 8 / 9 bones. Максимальная добавка Lv5 — 3 / 6 / 6 видимых Sprite2D соответственно; оружие гоблина и орка использует существующий Sprite. Текстуры общие для экземпляров, не копируются для каждого врага. Теоретический объём новых RGBA8 textures без сжатия — 8.75 MiB, не включая overhead и mipmaps. Финальный обычный Web pack — 2 041 292 bytes.

5. Реальные ApproachingEnemy всех трёх типов корректно выбирают пять уровней при HP ×1/2/4/8/16. Получение урона сохраняет уровень; static/animated fallback переключается обратно правильно.

8. Web export через MCP завершён успешно, threads=false. В Edge проверены все 15 комбинаций через реальные клики выбора уровня; у каждого врага attack на 0.5x выдаёт один impact event. 9. Обычная Web-сборка открывает меню, touch-эмуляция запускает бой с движущимися врагами и открывает настройки. Ошибок консоли нет.

Полный набор старых игровых сценариев не повторялся: gameplay scripts и balance resources не изменены. Выполнены целевые проверки visual, жизненного цикла и Web.

## Ручная приёмка

1. В браузерном review переключить уровни 1–5 у каждого врага: одобрить итоговые оружие, броню и щиты в движении.
2. Проверить walk и attack на 0.5x/1x, затем mirror: хват, шлем, щит и обе руки голема должны сохранять правильные слои.
3. Проверить маленькие игровые образцы: уровень читается, кожа и камень сохраняют цвет, гоблин меньше орка.
4. В обычной игре оценить общий вид.
