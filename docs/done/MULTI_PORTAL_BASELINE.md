# Снимок перед несколькими порталами

Дата: 08.10.2026. Сохранён текущий однопортальный вариант до изменений.

Локальный архив: `.tools/backups/procedural-before-multiple-portals-2026-10-08.zip`.
В архиве 16 файлов с относительными путями: конфигурация, ресурс баланса,
генератор, layout, Battlefield, GameManager, WaveManager, review-контроллер,
три сцены, проверочный скрипт и fixture, сценарий, план и отчёт фичи 11.1.
Содержимое всех записей сверено по SHA-256 с оригиналами.

Исходные настройки: один портал сверху; первый участок горизонтальный 2–5
переходов; остальные горизонтальные участки 2–5, вертикальные 1–3; вероятность
поворота 25–75%; длина дороги 1300–2500; 6–8 столбцов; 6–10 постаментов.
Порог покрытия постамента 160 при дальности 260. Поле Rect2(0, 0, 720, 1184).
HUD, настройки, арт, баланс волн и экономика входят в актуальное состояние проекта.

При отказе от нескольких порталов восстанавливать только относящиеся к этой
задаче изменения из архива, предварительно проверив последующие независимые правки.
Не выполнять reset всего проекта. Новые сцены ветвей и портала при откате удалить
только после восстановления ссылок. Синхронизировать Godot через MCP и обновить Web.
