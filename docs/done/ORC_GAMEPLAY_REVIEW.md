# Orc — интеграция в бой для финальной приёмки

08.10.2026. **Orc полностью принят пользователем**, включая gameplay integration и уменьшение Goblin на 20%. Animated default включён, static fallback сохранён. [План](ORC_ART_PLAN.md), [art](ORC_ART_REVIEW.md), [animations](ORC_ANIMATION_REVIEW.md).

[Открыть бой Orc](http://127.0.0.1:4175/preview/orc-gameplay/) · [анимации отдельно](http://127.0.0.1:4175/preview/orc-animation/) · [art и пять цветов одежды](http://127.0.0.1:4175/preview/orc-art/).

## Результат

`scenes/orc.tscn` сохраняет прежние ApproachingEnemy, stats, Visual, HealthBar и SlowIndicator; добавлен instance `OrcVisual`. HealthBar поднята над крупной головой: offsets −82/−55 вместо −66/−39, высота сохранена. Исходный `assets/orc.svg` остаётся доступным. После финальной приёмки `animated_visual_enabled=true` в обычной сцене.

ApproachingEnemy выбирает GoblinVisual либо OrcVisual с одинаковым контрактом. Gameplay по-прежнему считает движение по процедурной дороге, HP, slow, контакт с башней, outcome, награды и завершение волны. OrcVisual управляет только позой, направлением, цветом одежды и коротким остатком анимации после удаления enemy entity. Баланс Orc сохранён: базовые HP 60, скорость 120, урон башне 20, награда 5 маны.

Подготовка удара занимает последние 0.18 s до контакта с учётом оставшегося slow. Gameplay выбирает прежний кадр достижения башни, ставит позу impact и разрешает outcome ровно один раз. Отдельного источника урона от animation event нет. Попадания не задерживают движение или подготовку удара. После смерти цель сразу исключается из боя; только visual заканчивает death 0.32 s. После контакта заканчивается recovery attack. Visual tails освобождаются самостоятельно и при завершении/рестарте боя.

На Body, BackArm, FrontArm и обеих ногах назначен локальный ShaderMaterial с существующим equipment shader Goblin и маской Orc. Пороги и цвета EnemyStats сохранены: 60/120/240/480/960 HP; зелёный, оранжевый, красный, синий, фиолетовый. Меняются только ботинки, напульсники и видимая повязка. Head и Axe не имеют recolor material; кожа, ремни, наплечники, клыки и металл сохраняют цвета. Материал независим у каждого экземпляра.

`scenes/debug/OrcGameplayReview.tscn` наследует существующую игровую review scene. Debug-only скрипт начинает с штатной волны 3, чтобы не ждать открытия Orc; использует настоящие enemies, дорогу, summon, drag, projectiles, экономику и restart. Battlefield seed=101, summon seed=23. Нижняя панель переключает только Orc STATIC/ANIMATED и ставит бой на паузу. `?load_test=40` — отдельный development fixture для массовой проверки, не новая игровая механика. Review использует SessionProgress текущего процесса, постоянное сохранение игрока не записывает. Debug scenes/scripts исключены обычным export preset.

## Выполненные проверки

- Godot MCP: Godot 4.7.2, нужный проект, Compatibility; перед правками редактора unsaved=[]. Создание inherited review, material и nodes, сохранение/запуск/inspection/export выполнены через MCP.
- Native сравнение STATIC/ANIMATED на дороге 480 px с двумя поворотами и двумя попаданиями: оба достигают башни на кадре 239. При slow 50% на 1.513 s — оба на кадре 285. Расстояние 480 и остаточные HP 58 совпадают. Outcome=1, targetable=false, один impact у animated, animation position=0.18 s.
- Повторный lethal damage и повторный контакт после смерти не создают второй outcome. Death tail завершает анимацию и помечается на удаление. Два экземпляра с разными HP имеют независимые equipment materials/цвета.
- GPU-сравнение семи частей на пяти цветах: изменяются области одежды в пяти частях; зелёные skin pixels и защищённые области ремней/наплечников без изменений. Head/Axe полностью совпадают с исходным кадром. Пять цветов дополнительно посмотрены в настоящей сцене на дороге.
- Один сохранённый сценарий `feature_8_enemy_contracts`: passed, шесть шагов, runtime_errors=[]. Проверяет общие enemy contracts, сложности/квоты, boss lifetime, индивидуальные награды и сброс при рестарте. Остальной полный suite не запускался.
- Web Edge: мышь/touch STATIC/ANIMATED, точная остановка движения и animation frames на паузе, настоящие Frost slow и hit, убийство Orc с visual tail, возврат бойцов на башню, достижение башни с impact на 0.18 s, утрата targetability, нулевой остаток маршрута. Game Over освобождает tails; restart возвращает 100 маны, kills=0, projectiles=0, tails=0.
- Первый Web combat pass подтвердил slow, но не death: выбранная стационарная позиция защитников позволила Orc выйти из обстрела. Повторён затронутый combat сценарий с переносом защитников за Orc; смерть подтверждена настоящими снарядами. Уже пройденные Pause/STATIC/touch проверки не повторялись.
- Просмотрены снимки 450×800, 390×844 и 1280×720. Полоска HP над головой, visual остаётся в клетке дороги. Console/page/resource errors=[]. После свежего native запуска новых editor/runtime errors после seq=128 нет; после Web проверки ошибок после seq=129 нет.
- Короткий desktop Web load: 40 Orc, animated около 65 FPS / 325 draw calls / RAF mean 15.37 ms; static около 63 FPS / 163 draw calls / RAF mean 15.63 ms. Эти значения относятся только к текущему компьютеру и Edge, не к телефону.
- Web export через MCP однопоточный, без extensions. Временный main scene и фильтры export точно восстановлены; `project.godot`/`export_presets.cfg` без diff. Экспортированные сборки, снимки и диагностические helpers находятся в игнорируемых build/.tools.

Семь SVG textures 256×256 и одна mask — приблизительно 2 MiB RGBA8 без mipmaps, общие для экземпляров; восемь bones/один AnimationPlayer на Orc. Пять уровней используют тот же rig и textures. Draw calls выросли, но конкретной проблемы на коротком desktop тесте не обнаружено. Физический телефон и длительный прогон поздних волн не проверены. Mesh, pooling и новый VFX pass не добавлялись.

## Финальная ручная приёмка

Перед финальной приёмкой пользователь попросил уменьшить Goblin на 20%, чтобы Orc выглядел крупнее. GoblinVisual теперь 86.4/256 (0.3375) вместо 108/256; static Visual, HealthBar и SlowIndicator уменьшены тем же коэффициентом. Исправлен код mirror, чтобы поворот не восстанавливал старый размер; размеры в ArtAnimationTest, manifest и art preview синхронизированы. Размер Orc, gameplay entity position/scale, баланс и движение не менялись. Короткий MCP запуск подтвердил масштаб 0.3375 в обоих направлениях, STATIC/ANIMATED и сравнение с Orc 0.46875 в одной сцене; новых runtime errors после seq=130 нет. Общие боевые проверки не повторялись: правка затронула только visuals.

1. В бою принять читаемость Orc на дороге: голову/топор, повороты и отражение, полоску HP, отсутствие щелей и раздражающего движения.
2. Призвать защитников кнопкой-башней и посмотреть hit, Frost slow и death; без защитников посмотреть удар башне и исчезновение Orc после recovery. Проверить Pause и STATIC/ANIMATED, рестарт.
3. В art preview принять пять цветов только одежды; кожа, ремни, броня, лицо и топор должны оставаться прежними. При сомнениях отдельно посмотреть animations на 0.5× и игровом масштабе.

Финальная приёмка получена 08.10.2026. Animated default включён через Godot MCP: короткий запуск подтвердил новый visual без review override, HP=60 и сохранённый скрытый static fallback; новых runtime errors после seq=131 нет. Длительный combat pass не повторялся. Отчёты перенесены в docs/done с обновлением ссылок, для Orc создаётся отдельный commit. Push только по отдельному разрешению. Следующий этап — обсуждение плана Golem.
