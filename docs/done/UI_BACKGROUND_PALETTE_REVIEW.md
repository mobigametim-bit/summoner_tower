# Превью фона меню и нижнего HUD

10.10.2026. По запросу пользователя подготовлено только сравнение; изменения в игру не внедрялись. Пользователь решил сохранить текущий фон. Отчёт архивирован по его указанию.

Просмотр: http://127.0.0.1:4175/preview/palette/

| Вариант | Цвет | Назначение |
| --- | --- | --- |
| Белый | `#FFFFFF` | Светлый контраст с полянами; текст затемнён. Частицы на светлом требуют адаптации. |
| Чёрный | `#000000` | Максимальный контраст свечения; заметнее границы полян. |
| Пергамент | `#F2E8D5` | Тёплый светлый вариант с коричневым заголовком. |
| Лесной | `#142B25` | Рекомендуемый: связывает меню и арену, сохраняет контраст магии. |
| Сливовый | `#252038` | Магическая атмосфера, сочетание с порталом и кристаллами. |
| Текущий ночной | `#101522` | Контрольный вариант. |

Для каждого цвета показаны главное меню и игровой экран. На игровом экране меняется только фон нижней панели с волной, здоровьем, маной и шестерёнкой; поле и расположение объектов одинаковые. В светлых вариантах затемнены надписи и счётчики. Ассеты и эффекты не перерисовывались.

Включаемый на странице эскиз параллакса: верхняя и нижняя поляны слегка двигаются с разной скоростью; кнопки, заголовок и кошелёк стоят неподвижно. На touch предусмотрен медленный автоматический ход. `prefers-reduced-motion` отключает движение. Для боевого поля параллакс не предлагается.

Источник — текущие сцены, отрисованные через Godot MCP в отдельных runtime SubViewport; изменения цветов существовали только в процессе тестового запуска. Результаты сохранялись в `build/web/preview/palette/`; экспорт или замена production-сцен не выполнялись. Сохранения игрока изолированы существующей debug-сценой. Параллакс собирается из прозрачных снимков этих же ассетов; частицы на превью зафиксированы в кадре, это эскиз движения, а не готовая интеграция.

Проверено: загрузка всех 12 снимков; переключение 6 палитр; работа переключателя параллакса; широкое окно и 390×844 без горизонтального переполнения. После создания снимков игровой runtime не сообщил ошибок. Основная игра и принятые параметры баланса сохранены.

Итоговое решение пользователя: оставить существующее оформление без внедрения новых цветов и параллакса.
