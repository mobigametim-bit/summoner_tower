# Фича 17 — финальная проверка Web MVP

Дата: 11.10.2026. Статус: проверено и принято пользователем.

## Результат

Обычная браузерная сборка запускается через HTTP с главным меню, боем, постоянными улучшениями, настройками звука и согласованными fake-просмотрами. Баланс и игровые механики в рамках этой проверки не менялись. Основная сборка: [открыть игру](http://127.0.0.1:4175/?v=web-mvp17). Для воспроизводимого запуска: [WEB_RUN.md](../WEB_RUN.md).

Godot 4.7.2 / Compatibility, WebGL 2, однопоточный release export, без GDExtension. Версия подтверждена через Godot MCP и лог браузерного движка. Финальный экспорт выполнен через MCP, код завершения 0. Главная сцена и обычный preset восстановлены после подготовки проверочных сборок. Лицензии аудио включены в PCK.

## Объём проверки

Проведён один естественный браузерный забег с управлением через интерфейс: случайный seed 3492340916, три портала и 12 постаментов, волны 1–5, поражение на пятой. Проверочная сборка использует те же gameplay-сцены и ресурсы; отдельный Autoload только читает состояние. Playwright/Edge работает в отдельном профиле браузера внутри игнорируемой папки `build/`, поэтому сохранение пользователя не затрагивалось.

- Первая волна — пять гоблинов Lv1; вероятность декораций — 0,4.
- Призыв мышью и touch, слияние через touch drag с увеличением уровня и сохранением оплаченной стоимости, продажа мышью с возвратом половины стоимости. Отпускание вне допустимого слота сохраняет юнита.
- Пауза блокирует бой и призыв; продолжение, возврат в меню и повторный старт работают.
- После падения башни отмена fake-просмотра не выдаёт награду. Завершённый просмотр восстанавливает 50 ОЗ и текущую волну; повторное падение открывает результаты.
- За естественный забег заработано 8 кристаллов, удвоение выдаёт ещё 8. Рестарт сбрасывает волну, ману, временную статистику, возрождение и счётчик смен карт, сохраняя кошелёк.
- JSON прогресса с 16 кристаллами и настройки 37% / 24% подтверждены в IndexedDB, после refresh и полного закрытия/повторного открытия браузера.
- Музыка не запускается до первого действия; после ввода есть фактический аудиосигнал. Ноль на обоих ползунках даёт нулевой сигнал. Переключение музыки меню/боя проверено.
- Меню, настройки, бой, карточки, результаты и мета-улучшения просмотрены при 390×844, 720×1280 и 1400×900. Области кнопок укладываются в логический viewport.

В естественном забеге босс не был убит и не хватило валюты на покупку, поэтому дополнительно проверены только эти ветки:

- Существующая development-сцена `HudGameplayReview` завершает настоящую боссовую волну для проверки интерфейса. После выбора карточки возврат за двух бойцов — 22 маны, армия очищается, карта меняется один раз, через межволновую паузу запускается волна 6. Проверено отклонение возрождения с переходом к результатам.
- Покупка постоянного здоровья проверена через UI. Для проверки реального сохранения в отдельный тестовый профиль записан валидный начальный кошелёк 100 кристаллов: покупка оставляет 75, уровень становится 1, переживает refresh и открытие браузера. Новый забег начинается с 110 / 110 ОЗ. Это тестовые данные, не изменение экономики игры.

Финальная обычная сборка отдельно запущена после удаления проверочного Autoload: меню → настройки → бой → пауза → меню, touch и широкий экран. `getWebMvpAudit` и `getTowerReview` отсутствуют. Ошибок JavaScript, Godot runtime и неудачных запросов ресурсов в игре нет. Короткий запуск обычного меню через Godot MCP также не дал новых ошибок.

При подготовке проверки понадобилось обойти ошибку MCP регистрации нового UID: временный Autoload зарегистрирован по `res://`-пути. В служебной HTML-странице для записи тестового IndexedDB браузер запросил отсутствующий `/favicon.ico`; источник 404 отдельно подтверждён. Этот запрос не относится к игре; финальная игровая страница загрузила все ресурсы успешно. Все игровые утверждения дополнительного сценария выполнены; его первоначальный общий assert консоли остановился именно на этой служебной 404.

## Производительность и ограничения

117 снимков состояния во время активного боя, около 66 секунд основного цикла. Edge на текущем desktop: медиана 144 FPS, минимум 105 FPS; медиана времени обработки кадра 3,2 мс, 95-й процентиль 5,7 мс. Единичный максимум 73,5 мс; это не гарантия отсутствия кратких задержек. До 750 nodes, 134 draw calls и восьми одновременно активных врагов. Счётчик статической памяти в Web возвращает 0, поэтому оценка памяти по нему не заявляется.

Суммарный несжатый размер основных `index.*` — 47 353 960 байт (~45,16 MiB), включая WASM 39 514 754 байта и PCK 7 504 528 байт. Локальная загрузка финальной сборки — 1,234 с; интернет-загрузка на мобильной сети не измерялась.

Физический телефон, Safari/Firefox, фоновые ограничения мобильного браузера и массовая волна из 80 врагов в этом прогоне не проверялись. Touch эмулирован Chromium. Музыкальные стыки на слух остаются частью ручной проверки. Реальные реклама, платформенные сохранения и SDK относятся к отдельно согласуемой фиче 18.

Временные отчёты и скриншоты находятся в `build/web-mvp-*.json` и `build/web-mvp-*.png`, Playwright-сценарии — в `.tools/`; эти папки не коммитятся. Прежние сценарии целиком не повторялись. `scripts/debug/web_mvp_audit.gd` — небольшой наблюдатель для отдельной acceptance-сборки, исключён из обычного Web preset и не зарегистрирован в production Autoload.

## Ручная приёмка

1. Открыть обычную сборку, проверить звук после первого действия, оба ползунка и сохранение настроек после refresh.
2. Пройти свой забег: призыв, перенос/merge/продажа, босс, карточка и новая карта. Проверить удобство на телефоне, если он доступен.
3. Проверить поражение и возрождение, результаты, покупку постоянного улучшения и новый забег. После перезагрузки должны сохраниться валюта и улучшения, а незавершённый забег не сохраняется.
