# Русская локализация и выбор языка

11.10.2026. Реализация проверена и принята пользователем.

## Результат

- В настройках главного меню под громкостью появился выбор «Русский / English». Переключение применяется сразу, без перезапуска.
- Переведены подписи и подсказки меню, HUD, паузы, постоянных улучшений, всех шести карточек за босса, результатов, предложения возрождения и тестовой рекламы. Название SUMMONER TOWER сохранено.
- Русский — язык по умолчанию при отсутствии сохранённого выбора. Названия языков всегда написаны на своём языке.
- `LocaleService` использует стандартный `TranslationServer` и каталог `assets/localization/messages.ru.po` (56 сообщений). Английский использует исходные тексты.
- Язык хранится в отдельном `user://language_settings.json`, версия 1, запись через временный файл и rename. Отсутствующий/некорректный файл даёт русский по умолчанию; ошибки записи показаны в настройках. Прогресс и громкость не перезаписываются.
- Переключатель — реальные узлы в `scenes/ui/AudioSettingsOverlay.tscn`, созданные через Godot MCP.

## Проверки

- Через MCP подтверждены Godot 4.7.2, правильный проект, Compatibility renderer и отсутствие несохранённых сцен перед изменениями.
- Текущий Tsap-Tsarap содержит кириллицу и «ё». В Godot просмотрены настройки, постоянные улучшения, результаты и обе тройки карточек; русские подписи помещаются в окна.
- В Godot проверены переключение RU → EN → RU, успешная запись языка и повторный запуск с русским языком. Финальный запуск через MCP без отключения звука; новых runtime errors нет (после seq 119).
- Release Web экспорт через MCP успешен. В отдельном профиле Edge выполнены тапы по переключателю RU → EN → RU, проверена запись версии/языка в IndexedDB. Английский сохранился после обновления страницы и полного закрытия/повторного открытия браузера; это подтверждено также скриншотами настроек.
- Просмотрены Web UI на 390×844 и 1400×900: настройки на обоих языках, русские улучшения, HUD и пауза. Ошибок JavaScript и загрузки ресурсов нет.
- Отчёт автоматической Web-проверки: `build/localization-report.json`, скриншоты `build/locale-*.png`; временные материалы исключены из Git. Первые попытки сценария использовали клавиатуру и не выбирали второй пункт; финальная проверка использовала реальные тапы по пунктам списка.
- Полный боевой прогон не повторялся: изменение ограничено переводами и настройкой языка. Физический телефон не проверялся.

При подготовке редактор временно сообщил об ещё не зарегистрированном LocaleService; после регистрации Autoload и импорта запуск и экспорт прошли без этой ошибки. Автоматическую пересериализацию трёх балансных Resources редактором убрали из diff; баланс и игровая логика не менялись.

## Ручная приёмка

1. В главном меню открыть шестерёнку, выбрать English и Русский: заголовок меняется сразу; после перезапуска выбранный язык остаётся.
2. Посмотреть улучшения, карточки за босса и результаты: переводы понятны, подписи читаются, ничего не обрезано.
