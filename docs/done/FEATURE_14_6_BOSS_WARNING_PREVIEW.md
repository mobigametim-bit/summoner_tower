# Фича 14.6 — превью предупреждения BOSS

09.10.2026. Статус: отдельное превью проверено и принято пользователем. Интеграция разрешена с уточнением: один показ в начале каждой боссовой волны. Результаты интеграции описаны в [FEATURE_14_6_BOSS_WARNING_INTEGRATION.md](FEATURE_14_6_BOSS_WARNING_INTEGRATION.md).

По решению пользователя: большая центральная красная надпись BOSS, плавные переходы в белый и обратно. Существующий эффект портала сохраняется.

## Превью

- `scenes/ui/BossWarning.tscn`: прозрачный Control, Label с Tsap-Tsarap, font size 260 при логическом экране 720×1280, тёмная обводка и AnimationPlayer.
- Продолжительность 1,8 секунды. Три цикла красный `#ff3232` → белый → красный, лёгкая пульсация масштаба, плавное появление и исчезновение. Надпись не перехватывает ввод.
- `scenes/debug/BossWarningPreview.tscn`: существующее процедурное поле, три союзника и Boss для контекста. Предупреждение повторяется каждые 4 секунды; кнопка повторения находится справа сверху.
- Превью использует изолированное тестовое сохранение. Обычная main scene остаётся `scenes/main_menu.tscn`.

## Проверки

- Godot 4.7.2, Compatibility: проверены размер и центрирование, красный и белый кадры, автоматическое скрытие после анимации. Исправлены ошибка обновления списка script classes и потерянные свойства root при создании наследованной development scene через MCP; после исправления runtime errors отсутствуют.
- Однопоточный Web export отдельного превью: Edge 450×800 и 1280×720. Переходы цвета, центрирование, скрытие и повтор через touch проверены; browser console без ошибок.
- Preview export: `build/web/preview/boss-warning/index.html`; обычный Web export не перезаписывался. Commit и push этого этапа ожидают финальной приёмки интеграции.
