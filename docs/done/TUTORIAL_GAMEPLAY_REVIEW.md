# Обучение с Бородацием — игровая интеграция

19.10.2026. Статус: реализовано, проверено и принято пользователем.
Согласованный сценарий: [TUTORIAL_PLAN.md](TUTORIAL_PLAN.md).
Внешность и макеты приняты ранее: [TUTORIAL_PREVIEW_REVIEW.md](TUTORIAL_PREVIEW_REVIEW.md).

## Для игрока

- Первая карта учебного забега фиксирована: лес 6×9, один портал сверху,
  12 постаментов, seed 146. Первый лучник появляется в (1,2), переносится в (2,2),
  второй занимает освобождённое место. Индексы клеток здесь с нуля.
- После первого босса снова работает обычная генерация; последующие обычные забеги
  также случайны. Повтор обучения снова использует учебную карту.
- При первом посещении меню без отметки об обучении появляется Бородаций,
  включая игроков с уже существующим игровым сохранением.
- Кнопки пропуска нет. Повтор — настройки главного меню → «Повторить обучение».
- Обязательная часть: начало в лесу, портал/дорога/башня, здоровье, первый призыв,
  перемещение с радиусом, второй призыв, слияние, цвета уровней и старт боя.
- Первые два успешных учебных призыва гарантированно дают лучников по обычной цене,
  с действующими метаскидками. Неудачный призыв не расходует гарантию или ману.
- До завершения учебных действий первая волна не запускается. Перемещение и merge
  используют существующий игровой ввод и операции, включая два радиуса при наведении.
- После основной части условные подсказки показываются при первом знакомстве:
  типы бойцов, мана, заполненные слоты, продажа, swap, Lv3/Lv5, враги/способности,
  босс, карточки/цвета/переброс, экономика переезда, подарки, возрождение, итоги,
  мета, победа, биомы и останки кладбища.
- Показатели возврата/возрождения берутся из действующих данных. О переезде и
  обнулении остатка маны предупреждаем до нажатия карточки.
- Подсказки не требуют продажи, просмотра рекламы, покупки улучшения или поражения.
- 53 реплики на русском/английском; язык берётся из действующей настройки.

## Сохранение и пауза

- `user://tutorial.json` отдельно от прогресса/валюты/улучшений/настроек;
  хранит начало, завершение основной части и прочитанные сообщения.
  Поле skipped сохранено для совместимости формата, но всегда восстанавливается false;
  прежний пропуск без merge/combat возвращает игрока к незавершённому обучению.
- Старый `progress.json` не мигрируется и не сбрасывается этой системой.
- Просмотр меню не считается завершением: для completed нужны отметки слияния
  и последнего шага перед боем. Неполная прежняя отметка восстанавливается
  как незавершённое обучение без потери прочитанных реплик.
- До завершения основной части при новом запуске нужно заново создать учебных бойцов:
  текущий забег по прежним правилам не сохраняется. Уже прочитанные вступительные
  объяснения пропускаются; действия возобновляются в новом забеге по обычной цене.
- Ошибка сохранения явно показывается; будущая версия tutorial.json не перезаписывается.
- Игровая пауза управляется GameManager. Закрытие совета не снимает чужую паузу
  карточек, настроек или возрождения. Переход между сценами очищает подсказки и ссылки.
- Кнопки нового окна защищены от второго тапа по старой цели на 350 мс.
- Клавиатурный фокус остаётся внутри подсказки; Escape отменяет учебный жест,
  но не закрывает расположенное под подсказкой меню паузы.

## Реализация

- `scenes/ui/Tutorial.tscn`: постоянные Control, panel, portrait, text и buttons,
  созданные и сохранённые через Godot MCP. `Tutorial` — autoload CanvasLayer.
- `scripts/tutorial/`: отдельные хранение состояния, сценарий, координатор,
  окно и затемнение с отверстием для настоящего ввода.
- SummonManager сообщает об успешных призывах/переносах; UnitDragController
  ограничивает только активный учебный жест, сохраняя обычные отмену и touch.
- Бородаций — принятый вручную написанный SVG, 320×360, один UI-экземпляр.
- В настройках добавлена кнопка повтора; окно поднято выше декоративных частей меню.
  Тема аудиоползунков наследуется от AudioControls, прежний вид сохранён.
- Debug/review сцены по умолчанию не читают настоящее обучение. TutorialReview
  использует отдельные тестовые файлы и исключается из production export.

## Выполненные проверки

- Godot 4.7.2, Compatibility. Скрипты и ресурсы загружаются.
- Реальными mouse-действиями через MCP выполнены призыв, перенос и merge:
  100 → 80 → 55 маны; один Archer Lv2 с paid_mana=45; первая волна стартует после core.
- Отказ при 19 маны сохраняет цену, состояние и две гарантии.
- Двойной тап покупает только одного бойца и не подтверждает новое объяснение.
- По последнему решению пользователя пропуск полностью убран из сцены и обработчиков.
  В информационных шагах остаётся одна кнопка; в шагах действия кнопок нет.
- Пауза обычного совета возвращается в RUNNING. Карточки, настройки и revive остаются
  на своей паузе после закрытия объяснения. После отказа от revive доступны итоги.
- Escape при объяснении настроек не возобновляет бой; проверено настоящим key event.
- Боссовая последовательность cards → colors → reroll → map_80; выбор карточки
  возвращает игру к бою, меняет карту, оплаченная армия 45 даёт 36 маны.
- Мета: первый вход показывает объяснение; покупка вызывает отдельное подтверждение.
- `tests/support/tutorial_checks.gd`: roundtrip, повтор, восстановление старого пропуска, повреждённые данные,
  защита будущей версии; отдельное старое сохранение с кристаллами/метой/биомами не меняется.
- 106 локализованных вариантов проверены в окне; максимальная высота panel 365
  логических px, текст и действия помещаются в 720×1280.
- Web/Edge 390×844: весь core касаниями, отмена жеста, неподходящее нажатие,
  два лучника, merge, старт волны, перезагрузка до/после завершения.
- Ранее Web проверял сохранение пропуска и повтор через настройки; пропуск впоследствии
  удалён по решению пользователя. Просмотрены мобильное и широкое окно 1280×800.
- Production Web запускается без debug bridge. Browser console/pageerror пусты.
- Финальные целевые runtime-проверки без новых ошибок. Ошибки промежуточной сборки
  и выявленные проблемы повторного тапа/паузы исправлены до передачи.

## Сборки и ручная приёмка

Обычная игра: http://127.0.0.1:4175/preview/tutorial-play/

Актуальное изолированное обучение с адаптацией ориентаций (отдельные тестовые сохранения):
http://127.0.0.1:4175/preview/landscape/

Чтобы гарантированно начать проверку с первого шага в изолированном профиле:
http://127.0.0.1:4175/preview/landscape/?restart=1

Уточнение после замечания пользователя о пропавших подсказках в бою:
в чистой production-сборке переход меню → первая подсказка поля воспроизвёлся
корректно. Точная причина пользовательского случая пока не установлена.
По согласованному предложению карта закреплена, маркер завершения усилен;
повторяемость дороги/слотов/декораций и возврат случайной генерации проверены в Godot.
Полный путь на фиксированной карте дополнительно пройден в production Web без debug
bridge: сохранение IndexedDB содержит merge/combat, completed=true, skipped=false.
Отдельная проверка restart-ссылки подтвердила подсказку field, wave=0 и одинаковую
карту seed 146 при двух запусках. Browser console/pageerror пусты.

После удаления пропуска повторно проверены: отсутствие узла Skip, сигнала skipped
и метода skip в Godot; восстановление прежнего пропущенного обучения без сброса
основного прогресса; весь основной путь в production Web касаниями, включая перенос,
слияние и сохранение completed. Tab/Enter на шаге Play не обходят обязательное действие.
Browser console/pageerror пусты, новых runtime errors через MCP нет. Обе локальные
сборки выше обновлены; главная сцена проекта восстановлена в main_menu.tscn.

1. Оценить темп, шутки, читаемость и удобство шагов.
2. Призвать двух лучников, перенести и объединить; проверить оба радиуса.
3. Убедиться, что кнопки пропуска нет; повторить обучение через настройки после завершения.
4. Дойти до первого босса и проверить подсказки карточек и переезда.

Ограничения: физический телефон и полный длительный забег до всех редких подсказок
в этой задаче не проходились; редкие состояния проверялись целевыми сценариями.
Общая финальная проверка баланса кладбища остаётся отдельным этапом.
Ручная приёмка игрового обучения подтверждена пользователем 19.10.2026.
