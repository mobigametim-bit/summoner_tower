# Фича 14.4 — стрелы, оставшиеся во врагах

Дата: 09.10.2026. Статус: реализовано, проверено и принято пользователем.

## Решение пользователя

Вместо разлета частиц при попадании Archer стрела остаётся во враге до его смерти.

## Реализация

- Используется существующий `assets/arrow.svg`, без новых изображений. Переиспользуемая сцена `scenes/vfx/EmbeddedArrow.tscn` показывает древко и оперение; наконечник считается погружённым в тело.
- Только `scenes/arrow.tscn` включает прикрепление. Магические снаряды продолжают использовать свои эффекты попаданий.
- Стрела появляется при подтверждённом попадании перед существующим нанесением урона. Исчезнувшая цель, отменённый снаряд и истёкший срок жизни не создают стрелу.
- Для animated enemies родителем является `Skeleton2D/Root/Body`. Стрела следует за движением, отражением и анимацией корпуса. Размер учитывает разные масштабы rig и размер клетки.
- Точки входа и углы немного различаются. Для этого не используется генератор случайности волн/поля. Ограничения числа попавших стрел нет, таймер исчезновения не добавлен.
- Стрелы сохраняются на короткой анимации смерти и удаляются вместе с visual tail. При достижении башни, выходе из сцены или очистке карты действует существующий жизненный цикл визуала. Статичный fallback также поддержан.
- Урон, HP, скорость, дальность, cooldown, выбор цели и момент выпуска снаряда не изменены.

## Проверки

- Godot MCP: проект `C:/Gamedis/summoner-tower`, Godot 4.7.2, Compatibility.
- Lint: 82 сцены, 92 скрипта, ошибок и предупреждений нет.
- Native: по четыре настоящих попадания в Goblin, Orc, Golem и Boss; у каждого 4 стрелы и 460 HP из тестовых 500. После смерти удалились все 16 прикреплённых стрел. Статичный fallback также удаляет стрелу.
- Native: настоящий снаряд по гоблину на процедурной дороге; за контрольный интервал враг переместился на 96 px, стрела следовала за его корпусом. Проверены отмена снаряда без прикрепления и удаление стрелы после смерти.
- Web/Edge: четыре Archer атаковали четыре существующих типа врагов в development fixture `HudGameplayReview.tscn?arrow_test=1`. У каждого типа зафиксированы настоящие попадания, количество стрел соответствует потерянным HP. Число стрел увеличивается при новых попаданиях, на паузе состояние стабильно, выход в меню работает. Ошибок browser console нет.
- В этой небольшой Web fixture зафиксированы 144 FPS и 148 draw calls. Это не измерение предельной нагрузки и не проверка мобильного устройства: каждая оставшаяся стрела добавляет Sprite2D, поэтому очень большие скопления стрел требуют отдельного измерения, если появится просадка.
- Production Web export обновлён; проверены запуск главного меню и переход в игру без ошибок. Development fixture исключена из production preset, использует тестовое сохранение.
- Runtime errors через MCP отсутствуют; `git diff --check` проходит.

## Ручная приёмка

Игра: http://127.0.0.1:4175/?v=embedded-arrows-1

1. Призвать Archer и оценить читаемость торчащих стрел на игровом размере.
2. Посмотреть несколько попаданий в одного врага и движение/повороты с оставшимися стрелами.
3. Проверить, что стрелы исчезают после смерти врага.
