# Более раннее открытие уровней врагов

Дата: 11.10.2026. Реализовано, проверено и принято пользователем 11.10.2026.

Старые пороги Lv2–Lv5: 6 / 11 / 16 / 21. Новые: 3 / 6 / 8 / 11 — деление на два с округлением вверх. Lv1 доступен с первой волны. В `PowerBalanceConfig` вместо равномерного интервала используется массив `tier_unlock_waves`; игровые значения заданы в `resources/balance/power_balance.tres`. Открытие уровня расширяет доступные варианты выбора, но не гарантирует появление дорогого врага при недостаточном бюджете Мощи.

Через Godot MCP запущен реальный бой, проверены пороги для волн 1–12 и первая волна из пяти гоблинов Lv1. Существующая проверка планировщика пройдена: 200 сочетаний номера волны и Мощи армии, включая дискретные ОЗ, бюджет, предел количества и воспроизводимость seed. Новых runtime errors нет. Release Web export завершён успешно. Отдельный длительный браузерный прогон не выполнялся.

Ручная проверка: в новом забеге оценить более раннее появление оранжевых врагов с волны 3, красных с 6, синих с 8 и фиолетовых с 11; появление зависит от бюджета и случайного выбора.
