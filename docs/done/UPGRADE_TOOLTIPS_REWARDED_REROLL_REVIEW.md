# Подсказки меты и переброс за просмотр

14.10.2026. Выполнено по запросу пользователя; ожидается ручная приёмка. Commit/push этого этапа пока не выполнялись.

## Результат

Последующее уточнение14.10.2026: подсказка кнопки просмотра сокращена до «Переброс за просмотр», ограничение одного успешного раза за волну сохранено. Изменения названия/цен меты и автопродажи: [TOWER_SUMMON_ECONOMY_REVIEW.md](TOWER_SUMMON_ECONOMY_REVIEW.md).

- Все11 метакарточек показывают краткое описание действия при наведении, в том числе на максимальном уровне. Тексты RU/EN; величины берутся из MetaUpgradeConfig, цена покупки остаётся на самой карточке. Например, «Стоимость призыва / −2% за уровень».
- Подсказки состоят из двух коротких строк; размер TooltipLabel28 логических пикселей. Основные шрифты меню не изменены.
- После босса рядом с бесплатным перебросом есть кнопка с нарисованной SVG-иконкой стрелок и просмотра. Число1 означает доступную попытку,0 — использованную.
- Один успешный рекламный переброс на боссовую волну. Отмена или неуспех возвращают прежние карточки, попытка остаётся доступной. Следующая боссовая волна даёт новую попытку.
- Бесплатный переброс из меты сохраняется отдельно: один за забег; просмотр его не расходует. Оба переброса учитывают три/четыре варианта и существующие исключения пула.
- Во время просмотра бой остаётся на паузе, карточки и оба переброса блокируются. После завершения продолжается выбор, карта не меняется до выбора карточки.
- Используется существующий Fake AdService с placement UPGRADE_REROLL; реальный рекламный SDK не подключён. Счётчик успешного просмотра фиксируется до обновления UI; повторный callback и повторный клик не дают дополнительный переброс.

## Реализация и проверки

Сцена upgrade_choice.tscn, постоянные кнопки/row и сигналы изменены через Godot MCP. Код/PO/Theme/SVG — напрямую. Редактор4.7.2, Compatibility; несохранённых пользовательских сцен перед правками не было.

Визуальная проверка выявила длинные названия карточек, выходившие за границы. Названия теперь переносятся, font sizes36/28 для заголовка/описания; высота кнопки учитывает minimum size содержимого после расчёта ширины. Старые асинхронные расчёты отменяются revision при новом предложении или закрытии. Проверен набор четырёх длинных карточек: всё помещается в портретный720×1280, реальные окна450×800.

Проверено:

- Native: cancel сохраняет предложение/попытку, FAILED сохраняет попытку, SUCCESS блокирует второй просмотр этой волны, повторный completed не выдаёт награду. Бесплатный переброс независим. На волне10 после использованной попытки волны5 кнопка снова доступна. Полный тестовый таймер3сек работает при паузе.
- Native: выбор карточки во время просмотра заблокирован; после просмотра выбор и обычная смена карты работают. Старое возрождение даёт50HP; удвоение награды даёт ещё20 кристаллов и защищено от повторного callback.
- Native:11 подсказок содержат описания, не текст покупки за кристаллы; значения совпадают с настройками.
- Web/Edge450×800: реальные hover-подсказки и touch-кнопки, cancel, полный просмотр, однократность, отдельный бесплатный переброс и выбор после просмотра. Отчёт build/rewarded-reroll-report.json: без console/pageerror/ошибок загрузки.
- После исправления layout проверка Web повторена; после отдельного уменьшения TooltipLabel повторно просмотрена длинная подсказка. Снимки build/meta-effect-tooltip.png, build/meta-choice-tooltip.png, build/rewarded-reroll-buttons.png, build/rewarded-reroll-watching.png.
- Release Web: обычный запуск, touch Play, настройки/пауза и широкое окно прошли без ошибок. Обе Web-сборки обновлены; main_scene восстановлена на main_menu. После итоговых проверок новых runtime errors нет.

Физический телефон и настоящий рекламный провайдер не проверены. QA использует отдельное тестовое сохранение и не изменяет обычный прогресс игрока.

## Ручная приёмка

Игра: http://127.0.0.1:4175/?v=rewarded-reroll-1

Быстрая проверка окна карточек: http://127.0.0.1:4175/preview/upgrade-expansion/?card=9&v=4

Подсказки меты: http://127.0.0.1:4175/preview/upgrade-expansion/?mode=meta&v=4

1. Навести на разные метаулучшения: описание эффекта читается целиком, стоимость остаётся в карточке.
2. Нажать кнопку с иконкой просмотра, отменить: карточки и попытка сохранены.
3. Дождаться полного просмотра: варианты обновились, рекламная кнопка стала недоступной, бесплатный переброс остался.
4. Выбрать карточку и продолжить бой; на следующем боссе рекламная попытка снова доступна.
