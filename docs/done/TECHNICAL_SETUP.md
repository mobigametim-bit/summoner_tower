## Объём фичи

Главное меню `SUMMONER TOWER` с кнопкой `PLAY` открывает пустую сцену `Game`.
Постоянный интерфейс хранится в сцене и доступен в редакторе. Переход обрабатывает небольшой скрипт меню; повторное нажатие защищено до смены сцены.
Бой, башня, враги, экономика, улучшения и сохранения добавляются отдельными фичами плана.

## Структура

- `scenes/main_menu.tscn` — стартовый экран.
- `scenes/game.tscn` — пустая игровая сцена с корнем `Node2D`.
- `scripts/ui/main_menu.gd` — переход по кнопке `PLAY`.
- `assets/` — будущие исходные визуальные и звуковые ресурсы.
- `resources/` — будущие данные баланса и другие `.tres`.
- `docs/` — требования, план и техническая документация.
- `addons/godot_forge/` — существующее подключение редактора и runtime к MCP.

## Окно и ввод

Логическое разрешение — `720 × 1280`. Начальный размер desktop-окна — `450 × 800`.
Масштабирование `canvas_items`, aspect `keep` сохраняет вертикальную композицию; на широком экране допустимы боковые поля.
Меню использует полноэкранные anchors и контейнеры. Кнопка достаточно крупная для касания.
Мышь и touch используют стандартный сигнал `Button.pressed`; `emulate_mouse_from_touch` включён, `emulate_touch_from_mouse` выключен. Дополнительного обработчика touch нет, чтобы не дублировать нажатие.
Синтетические touch-события в desktop runtime не заменяют проверку на физическом touch-устройстве.

## Web export

Preset `Web` хранится в `export_presets.cfg`; целевой файл — `build/web/index.html`.
Экспорт исключает документацию и служебные файлы. Существующий `ForgeRuntime` и его зависимости остаются доступны: без подключённого отладчика его `_ready()` отключает обработку. Плагин не удаляет autoload при экспорте; исключать весь `addons/godot_forge/` при таком autoload нельзя.
Локальная папка `.tools/` исключена из импорта Godot файлом `.gdignore`, чтобы тестовые шаблоны MCP-сервера не попадали в проект и не создавали ошибки GDScript.
Web-сборку следует открывать через HTTP, а не `file://`.

`C:\Users\Тим\AppData\Roaming\Godot\export_templates\4.7.2.stable`.
