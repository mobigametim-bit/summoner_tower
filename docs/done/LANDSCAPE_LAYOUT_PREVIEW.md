# Горизонтальный интерфейс — предложение

18.10.2026. Превью принято пользователем, разрешён переход к игровой интеграции.

Адрес: http://127.0.0.1:4182/art/concepts/landscape/

Макеты: `art/concepts/landscape/index.html`, снимки `phone.png`, `tutorial.png`,
`tablet.png`, `menu.png` рядом. Все изображения взяты из текущих SVG проекта;
генераторы изображений не использовались. Каталог исключён из импорта `.gdignore`.

Предлагается:

- В горизонтальной ориентации поле 9×6 вместо 6×9: количество клеток остаётся 54.
  На макете 12 постаментов. Фактический диапазон 10–15 менять не предлагается.
- Телефон 16:9: поле занимает всю высоту, HUD справа; там волна, здоровье, мана
  и большая кнопка настроек. Башня остаётся кнопкой призыва с числом у основания.
- Планшет 4:3: HUD в одной строке сверху, поле занимает ширину сразу под ним.
- Обучение: рамка выделяет цель, панель и портрет размещаются по другую сторону;
  кнопки пропуска нет.
- Меню: название биома над декорацией слева; у правого края одна вертикальная группа:
  кристаллы, старт, улучшения, настройки, без общей прямоугольной подложки.
  Стрелка биомов 110×110, как остальные кнопки, центрирована в промежутке
  справа от картинки и по её вертикальной середине; иконка центрирована внутри кнопки.

Карта нарисована вручную для демонстрации композиции. Превью не выполняет
генерацию, бой или расчёт баланса. Переключение экранов и показ радиуса работают.
Проверены загрузка всех SVG/шрифта, отсутствие ошибок JS и переполнения страницы
при окне 844×390. Просмотрены все четыре снимка.

Изменение формы карты — продуктовое решение: пути и расположение слотов изменятся,
хотя клеток столько же. После принятия нужно адаптировать генератор и учебную карту,
координаты указателя, drag/merge/радиусы, модальные окна, безопасные отступы мобильных
браузеров и поворот устройства. Статы и экономику автоматически не менять.

Этот отчёт фиксирует принятую компоновку. Игровая интеграция проходит отдельную приёмку.
