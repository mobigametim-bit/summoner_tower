# Стрелки биомов рядом с кошельком

16.10.2026. Реализовано, проверено и принято пользователем.

- Название выбранного биома и отдельная строка навигации удалены из главного меню.
- Стрелки стоят у левого/правого краёв игрового экрана, с отступом 24 логических
  пикселя. Центры кнопок совпадают по вертикали с центром кошелька кристаллов душ.
- Стрелка вправо показывает следующий открытый биом, влево — предыдущий.
  При единственном открытом биоме навигация скрыта. Кошелёк остаётся в центре.
- Кнопки сохранены в `main_menu.tscn`, перенесены через Godot MCP; горизонтальные
  позиции заданы anchors, вертикальная позиция обновляется после размещения кошелька
  контейнером и при изменении размера окна. Постоянного обновления каждый кадр нет.
- Открытая настройка и начало перехода между экранами блокируют стрелки.
  Сохранение выбора, замок/«Скоро» для неготового кладбища и игровые правила не менялись.

## Проверки

Godot MCP: Summoner Tower, Godot 4.7.2, Compatibility. Lint двух затронутых
скриптов без замечаний. Проверены скрытое/открытое состояние, оба направления,
отсутствие узла названия, боковые отступы, совпадение высоты с кошельком,
блокировка навигации при настройках. Новых runtime errors нет.

Выполнены release exports обычного Web и development-меню. Основная сцена
возвращена к `scenes/main_menu.tscn` после экспорта.
Edge: 390×844/DPR3, 768×1024 и 1400×900. На всех трёх размерах touch переключает
биомы, центры кошелька и стрелок имеют y=610 при логическом экране 720×1280.
Проверены сохранение выбранного кладбища после reload, возврат в лес и запуск игры.
Просмотрены мобильный лес и планшетный placeholder кладбища: переполнения нет.
Ошибок JavaScript/Godot/HTTP нет. Физические устройства не проверялись.

Тестовый профиль изолирован: `user://biome_framework_review.json`.
Изменения боевой логики не выполнялись; повторный прогон финала волны 25 не требовался.
