# Звук выстрела жреца

19.10.2026. Реализовано, проверено и принято пользователем с итоговой громкостью
25% от первоначального варианта.

Добавлен отдельный эффект `magical_6` из Magic Spell SFX (JaggedStone),
распространяемый по CC0 1.0:
<https://opengameart.org/content/magic-spell-sfx>.
Скачан исходник `magical_6_0.ogg`, преобразован в
`assets/audio/sfx/priest_cast.mp3` — 128 kbps, 44,1 kHz, стерео, 1,11 секунды,
около 19 КБ. Темп, высота тона и длительность сохранены.
Автор, адрес загрузки, обработка и SHA-256 добавлены в
`assets/audio/SOURCES.json` и `assets/audio/LICENSES.txt`;
полная лицензия находится в `assets/audio/licenses/CC0-1.0.txt`.

Событие `priest_cast` заменяет прежний звук ледяного мага у жреца.
Оно вызывается на существующем кадре выпуска обычного снаряда и снаряда
способности «Освящение». По двум последовательным правкам пользователя громкость
дважды уменьшена вдвое: −20,0412 dB вместо исходных −8 dB
(множитель 0,25 по линейной шкале). Общий ползунок SFX
и существующий лимит трёх боевых голосов сохранены. Частые одновременные
запуски ограничены прежним интервалом 0,12 с; бой на паузе не воспроизводит эффект.
Баланс и тайминги атаки не менялись.

## Проверки

- Godot MCP: правильный проект, Godot 4.7.2, Compatibility, MP3 импортирован
  без зацикливания, ресурс зарегистрирован; в реальном `game.tscn` жрец
  атакует и воспроизводит новый stream. Блокировка воспроизведения на паузе проверена.
- Сцену `PriestGameplayReview` привели к текущему типу контейнера счётчиков
  (`GridContainer`): старая встроенная версия HUD не запускалась после адаптации UI.
- Edge/Web: после пользовательского клика эффект декодируется и играет у
  жреца Lv1 и Lv5; WebAudio сообщает новые источники длительностью 1,11 с,
  контекст `running`, ненулевой аудиосигнал; ошибок pageerror/console нет.
- Сохранения тестовой сцены находятся только в памяти и не меняют прогресс игрока.

## Ручная проверка

[Бой для прослушивания](http://127.0.0.1:4175/preview/priest-audio/).
Кликнуть или тапнуть по игре для разрешения звука браузером, переключить Lv1/Lv5.
Проверить характер эффекта, комфорт громкости рядом с музыкой и звучание
при нескольких выстрелах подряд. Звучание с итоговой громкостью принято
пользователем; физический телефон отдельно не проверялся агентом.
