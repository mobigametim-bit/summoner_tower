# Радиус атаки при перетаскивании

11.10.2026. Реализовано и принято пользователем.

Круг появляется после начала перетаскивания и следует за бойцом. Заливка полупрозрачная (14%), граница заметнее (65%); цвет совпадает с одеждой соответствующего уровня: зелёный, оранжевый, красный, синий, фиолетовый.

Радиус взят из `UnitStats.attack_range`: Archer 300, Mage 260, Frost Mage 280 мировых px. Центр совпадает с перемещаемой игровой позицией бойца, от которой бой рассчитывает дистанцию. Масштаб SVG и размер постамента не умножают дальность. Круг рисуется под перетаскиваемым бойцом и под HUD; не изменяет бой и не перехватывает ввод.

Через MCP в `scenes/game.tscn` создан `World/DragController/AttackRangePreview` с небольшим скриптом `scripts/ui/attack_range_preview.gd`. После отпускания, отмены и остановки drag круг скрывается вместе с существующим превью. В Web дополнительно подписались на `window.resize`: CSS-масштабирование холста не всегда вызывает Godot `NOTIFICATION_WM_SIZE_CHANGED`. Подписка снимается при удалении контроллера.

## Проверки

- Godot MCP: 15 сочетаний (три типа × пять уровней), мышь, соответствие радиуса/цвета, отсутствие масштабирования радиуса, скрытие после release. Проверены touch drag и отмена касания; визуально просмотрен синий круг Lv4.
- Web: реальные mouse/touch события в отдельной проверочной сборке. Проверены цвет/радиус Lv1, Escape, touchcancel, успешный перенос в пустой слот, скрытие круга при изменении размера окна 390×844 → 1400×900. Сохранение игрока не использовалось.
- Первая браузерная проверка читала снимок до обработки Escape; добавлено ожидание кадра. Следующая выявила отсутствие отмены жеста при Web resize; исправление подтверждено повторным целевым сценарием. Финальный отчёт `build/drag-range-report.json`: все проверки пройдены, JavaScript/resource errors отсутствуют.
- Временный QA Autoload и preset сняты; обычная release Web-сборка обновлена через MCP. Финальный запуск Godot без отключения звука, новых runtime errors нет (после seq 157).
- Автоматическую пересериализацию трёх балансных Resources убрали из diff. Полный боевой набор проверок не повторялся; физический телефон не проверен.

Ручная проверка: перетащить бойца разных уровней, оценить прозрачность/цвет и дальность; отпустить или отменить жест — круг должен исчезнуть.
