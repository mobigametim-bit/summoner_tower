# Кладбище — приёмка концептов

16.10.2026. Пользователь: «отлично, мне все нравится».

Приняты внешний вид четырёх обычных врагов, Жреца света и Лича на пяти уровнях,
две формы голема плоти, земля, дорога, постамент, портал, десять декораций
и пример общей композиции поля. Скелет исправлен по замечанию пользователя:
отдельные рёбра, позвоночник, таз и тонкие кости конечностей с просветами.

Исходники и просмотр: [art/concepts/graveyard](../../art/concepts/graveyard/index.html).
SVG созданы собственным кодом; генераторы изображений и сторонний art не использовались.
Концепты исключены из импорта/экспорта Godot через `.gdignore`.

Проверки: 47 изображений загружаются в Edge без ошибок; геометрия 32 персонажных SVG
помещается в canvas; просмотрены листы, вариант 100 px и общая композиция.
На ширине 390 px проверены фильтры и отсутствие горизонтального переполнения.
Это статические концепты: parts, rig, анимации, VFX и gameplay ещё не реализованы.
Игровые сцены, runtime и Web export для этой стадии не изменялись и не перезапускались.

Принятые продуктовые ответы и оставшееся уточнение по архетипам находятся
в активном [пайплайне биома](../BIOME_2_GRAVEYARD_PIPELINE.md).
Сам пайплайн остаётся в `docs/`, поскольку внедрение биома ещё впереди.
