# Фича 14.9 — лёгкая тряска

09.10.2026. Реализовано, проверено в Godot и Web и принято пользователем. Остальные пункты последнего списка не развиваются.

## Результат для игрока

- Сильный удар по башне: смещение камеры до 2 логических px по каждой оси с затуханием за 0,18 секунды. Порог — потеря от 20 HP за одно событие: текущие удары Orc, Golem и Boss; Goblin с уроном 10 не запускает эффект.
- Начало боссовой волны: до 3 px по каждой оси за 0,28 секунды, один раз на волну. Дополнительные события спавна и убийства не повторяют импульс.
- HUD и модальные окна остаются неподвижными. Позиции игровых объектов не изменяются; используется только `Camera2D.offset`.
- Повторный сильный удар заменяет текущую тряску, амплитуды не складываются. Камера возвращается точно в ноль. Пауза, выход из боя, смена карты и выход из сцены останавливают эффект.

## Реализация

- `scenes/vfx/ScreenShake.tscn` — Camera2D с фиксированной верхней левой привязкой и GFFPlayer, добавлена через Godot MCP в игровую сцену.
- `scripts/visuals/screen_shake.gd` — два небольших обработчика существующих сигналов `Tower.health_changed` и `WaveManager.state_changed`, однократность появления босса и очистка эффекта.
- `resources/visuals/feedback/tower_hit_shake.tres` и `boss_intro_shake.tres` — параметры установленного бесплатного GFFCameraShake. Код поставщика не изменялся.
- Длительность, амплитуда и порог не меняют боевой баланс. Начальная камера соответствует прежнему canvas transform; нет приближения, вращения и движения самих entities. Существующая логика drag учитывает canvas transform.

## Проверки

- Godot 4.7.2/Compatibility, lint: 85 сцен, 95 скриптов, ошибок и предупреждений нет.
- Native через MCP: первоначальный canvas transform единичный; удар 10 HP не запускает эффект, 20 HP запускает. После удара offset ровно нулевой, World.position и HUD.global_position не меняются.
- Native: боссовой волне соответствует один импульс; повторные state_changed не повторяют его после завершения. Пауза сбрасывает смещение в ноль, асинхронный эффект не продолжает менять offset во время паузы. Runtime errors отсутствуют.
- Web/Edge: настоящая пятая волна в development fixture, измеренные смещения не выходят за заданные пределы. Проверены слияние через мышь и призыв через touch во время активной тряски; операция и расход маны корректны, HUD стабилен. Пауза/продолжение и возврат в меню прошли без остаточного смещения и ошибок browser console.
- Однопоточный production Web export обновлён, проверен запуск игры и просмотр поля. Проверка использует изолированное сохранение. `shake_test=1` и его Timer присутствуют только в development-сцене; обычная игра получает тряску только от игровых событий.
- `git diff --check` проходит. Длительный прогон баланса не повторялся; проверялись новая камера, связанные риски ввода и завершение эффектов. Физическое мобильное устройство и предельная нагрузка не измерялись.
