# Mage — SVG art и ручная приёмка внешнего вида

07.10.2026. **Mage полностью принят пользователем.** Этот отчёт сохраняет результаты art gate по [плану](MAGE_ART_PLAN.md). Последующие принятые этапы: [rig/animation gate](MAGE_ANIMATION_REVIEW.md), [финальная приёмка](MAGE_GAMEPLAY_REVIEW.md). Push только по отдельному разрешению.

## Просмотр и результат

[Mage art preview](http://127.0.0.1:4175/preview/mage-art/) — новая ручная отрисовка рядом с `art/references/mage.png`. На странице показаны 100/140/180 px, постаменты сеток 6/7/8 столбцов, реальные малые размеры для ширины экрана 390 px, сравнение с принятым Archer и пять цветов только ткани. Можно выбирать отдельную часть, показывать pivots и зеркальную сборку.

Исходники: `art/source/mage/master.svg`, восемь SVG в `parts/`, `rig_manifest.json`, `README.md`, `review.html`. Все production SVG отрисованы вручную кодом, без генераторов, растровых вставок, Krita и сторонних sprites. Неизменённые gameplay scene/script: `scenes/mage.tscn`, `scripts/combat/combat_unit.gd`; прежние `assets/mage.svg`, fireball и баланс сохранены.

Силуэт повторяет основные формы reference: широкая синяя шляпа с загнутой вершиной, белые волосы/борода, небольшая мантия, короткие конечности, деревянный посох с большим голубым кристаллом. Мелкие складки/парящие украшения упрощены. На первом просмотре поля шляпы перекрывали один глаз; форма исправлена до передачи результата.

Parts: body, head, hat, arm_back, arm_front, leg_left, leg_right, staff. Hat использует pivot Head без отдельной кости; подготовлено 8 будущих bones вместе с Root. Origin=(128,128), ступни около y=239; полный canvas 256×256, без trimming. Пивоты/слои/overlap описаны в source README и manifest. Посох за кистью и перед корпусом.

Палитра reference сохраняется в source master. SVG-примерка уровней меняет только три цвета ткани, сохраняет кожу, волосы, бороду, золото, сумку, ботинки и посох. Это проверка art direction; Godot shader/material ещё не создан и не подключён.

## Выполненные проверки

- Godot MCP: подключён нужный проект `C:/Gamedis/summoner-tower`, Godot 4.7.2-stable official, Compatibility. Несохранённых сцен нет, main scene остаётся main_menu.
- Master и все 8 parts импортированы как Texture2D 256×256. Master просмотрен через MCP. Новых editor errors при импорте/preview нет; на этом art gate сцена MageVisual ещё не создавалась.
- XML всех SVG корректен, все viewBox совпадают с 0 0 256 256. Master использует компактные формы, без embedded bitmap. Browser canvas сравнение сборки восьми parts и master: max difference=0/255.
- Границы силуэта на 256×256: (25,20)–(245,242), обрезания холстом нет. Прозрачный фон сохранён.
- Edge: reference, новая сборка, scale samples и опора на постаменте просмотрены при 1000×900 и 390×844. На телефонном viewport горизонтального overflow нет. Выбор parts, pivots и mirror работают; console/page/resource errors=[] в одном целевом проходе.
- SVG-примерка пяти цветов: Head, Staff и обе ноги идентичны на всех уровнях; остальные fills меняются только по трём исходным цветам ткани. Визуально лицо/кристаллы/золото сохраняют цвета.

Gameplay scenarios и Web game export не повторялись: art не подключён к игре, игровой код и сцены не менялись. Проверка gameplay/поворотов суставов/animation timing следует после соответствующих ручных gates. Физическое мобильное устройство не проверялось; текущая проверка малого размера выполнена на desktop browser viewport.

## Ручной checklist

1. Принять силуэт и пропорции рядом с reference и Archer: шляпа, лицо, посох, короткие руки/ноги.
2. Проверить outline и простоту деталей при 100/140/180 px и на малых постаментах.
3. Принять слои: рука с посохом перед корпусом, посох за кистью, шляпа перед головой; оба глаза читаются.
4. Проверить пять цветов ткани: лицо/волосы/борода/золото/ботинки/посох сохраняют цвета.
