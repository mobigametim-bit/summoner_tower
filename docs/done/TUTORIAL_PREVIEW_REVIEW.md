# Бородаций и макеты обучения

18.10.2026. Статус: art/UI превью принято пользователем.
Сценарий и три продуктовых решения подтверждены пользователем:
[TUTORIAL_PLAN.md](../TUTORIAL_PLAN.md).

## Результат

- Собственный SVG-концепт наставника `art/concepts/tutorial/borodacius.svg`:
  синяя мантия/шляпа, золотая отделка, длинная светлая борода, посох и указывающая рука.
  Формы написаны вручную, без image generators и сторонних изображений.
- Отдельный HTML-макет на игровых снимках, полученных через Godot MCP:
  знакомство, призыв через башню, слияние с текущим/будущим радиусами и
  предупреждение о переезде после босса.
- Рисунок показан крупно и уменьшенным в композиции 720×1280.
- Кнопки переключают макеты, пропуск убирает подсказки, нажатие выделенной башни
  демонстрирует переход к следующему макету. Реального игрового обучения ещё нет.
- В сцене слияния лучники добавлены в HTML поверх снимка поля; это макет,
  не проверка настоящего drag или игровой системы обучения.
- Карточки после босса — композиционный пример, не новые настройки баланса.

## Проверки

- Godot MCP: нужный проект, версия 4.7.2, несохранённых сцен нет.
- Снимки сделаны в изолированной тестовой сессии; пользовательский прогресс не изменялся.
- Просмотрены все четыре макета и крупный рисунок.
- Edge: ширина 390 px и окно 1280×1000, загрузка SVG/PNG/Itim/иконок,
  отсутствие горизонтального переполнения, диалоги внутри экрана, переходы/пропуск.
- Только HTML/SVG preview: отдельный Web export игры не требовался.
- Касания на реальном телефоне и работа игрового обучения пока не проверялись.
