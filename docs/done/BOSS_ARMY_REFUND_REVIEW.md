# Возврат 80% маны при смене карты

11.10.2026. Принято пользователем.

После завершения боссовой волны и выбора карточки вся армия автоматически продаётся за 80% реально вложенной маны. Для объединённого бойца берётся сумма стоимости его составляющих; округление вниз выполняется отдельно для каждого бойца. Ручная продажа через башню сохраняет 50%. Mana Flow не увеличивает возврат.

Проценты разделены в `SummonConfig`: `refund_percent = 50`, `map_change_refund_percent = 80`, значения заданы в `resources/balance/summon_config.tres`. Момент продажи, очистка слотов, сброс удорожания призыва и автоматическое продолжение волн сохранены.

Проверки через Godot MCP: бойцы за 20/25/30 маны, первые два объединены, после убийства босса и остальных врагов волны 5 и выбора карточки возвращено 60 маны. Проверены очистка армии, новый seed карты, продолжение волн и отсутствие повторного возврата при повторном выборе/продаже пустой армии. Ручной возврат 25 → 12 и автоматический 31 → 24 проверены отдельно. Повторно пройден существующий целевой сценарий разрушения башни боссом и возрождения: выбор карточки, продажа и карта выполняются однократно; ложного убийства босса нет. Игровое сохранение пользователя не изменялось: использовано тестовое состояние SessionProgress.

Release Web экспорт обновлён через MCP. В браузере проверены загрузка и старт боя без ошибок JavaScript/ресурсов; боссовый переход проверен в Godot. Финальных runtime errors нет (после seq 130); первая подготовка проверки задержалась до завершения тестового забега и была повторена с немедленной подготовкой в одном вызове MCP. Полный боевой прогон и физический телефон не повторялись.

Ручная проверка: завершить боссовую волну, выбрать карточку и проверить прирост маны/пустую армию на новой карте; обычная продажа бойца по-прежнему возвращает половину вложенной маны.
