## Перед показом

1. Открыть ссылку на телефоне через Wi-Fi; дождаться меню.
2. Начать бой, тапнуть башню для призыва и проверить перетаскивание бойца.
3. Убедиться, что после тапа слышны музыка/эффекты и подходят уровни громкости.
4. Проверить повторное открытие ссылки с мобильным интернетом.

Первая загрузка — около 48 МБ; offline/PWA-режима нет, для показа нужен интернет.
Прогресс отдельный для браузера на публичном адресе и не переносится с локальной версии.
Реклама остаётся согласованной fake-реализацией без платформенной SDK.

Настройки источника Pages сверены с [официальной документацией GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
