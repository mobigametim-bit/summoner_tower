# Плотность декораций — 40%

Дата: 11.10.2026. Реализовано, проверено и принято пользователем 11.10.2026.

В `resources/balance/battlefield_config.tres` и значении по умолчанию `BattlefieldConfig` вероятность декорации уменьшена с 55% до 40%. Проверка выполняется отдельно для каждой клетки окружения. Дорога, постаменты, башня и порталы исключены; 11 видов декораций остаются равновероятными. Пустая клетка имеет вероятность 60%; конкретный вид декорации — примерно 3,64% на клетку окружения.

Через Godot MCP подтверждены проект, Godot 4.7.2 / Compatibility и загруженное значение 0,4. На новой карте — 17 декораций на 41 клетку окружения, 12 постаментов и один портал. Карта просмотрена в runtime; после исправления пути в разовом запросе inspection новых ошибок нет. Release Web export завершён успешно. Проверка в браузере в рамках этой небольшой правки отдельно не выполнялась.

Ручная проверка: начать новый забег и оценить плотность окружения. На конкретной карте доля случайная, точного заполнения 40% не гарантируется.
