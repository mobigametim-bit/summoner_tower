# Башня — превью частиц энергии кристалла

09.10.2026. Превью принято пользователем после удвоения радиуса, количества и размера частиц. Пользователь разрешил внедрение в башню; оно описано отдельно в [TOWER_CRYSTAL_VFX_INTEGRATION.md](TOWER_CRYSTAL_VFX_INTEGRATION.md). Этот отчёт фиксирует этап визуальной приёмки. Фича 14.1 остаётся на ручной приёмке.

Ссылка: <http://127.0.0.1:4175/preview/tower-energy/>.

## Что показано

- Существующий TowerVisual без изменения исходного арта: крупный план 320 px и пример игрового размера 116 px.
- В покое: 24 голубые частицы с яркой сердцевиной, плавным исчезновением и медленным движением вокруг кристалла; мягкий ореол позади него.
- При тапе: 40 частиц расходятся наружу; на короткое время усиливается ореол. Оригинальная анимация tap башни сохраняется.
- Тап по любой панели или кнопке «Повторить всплеск» одновременно запускает оба образца для сравнения. Кнопка «Свечение» позволяет отключить/включить фоновый эффект.

Размер одной текстуры 32×32, частицы примерно 42–67 px до масштабирования башни. В игровом образце это примерно 19–30 логических px; в окне 450×800 около 12–19 физических px. Эффекты рассчитаны на заметность, без мелкой пыли.

По следующей правке пользователя количество и радиус обоих эффектов удвоены. Радиусы фонового кольца теперь 96–124 px вместо 48–62, область появления всплеска 36 вместо 18. Скорость и ускорение движения также удвоены, чтобы дистанция разлёта за прежнее время была вдвое больше. Радиус ореола удвоен. На этом этапе размер отдельных частиц и длительность эффектов сохранены.

Следующей отдельной правкой размер частиц удвоен: фоновые scale_amount 1,3–1,9 вместо 0,65–0,95; всплеск 1,4–2,1 вместо 0,7–1,05. Количество, радиусы и время жизни при этой правке не менялись.

## Техническая изоляция

На этапе превью сцены, скрипты, ресурсы и SVG находились в debug-каталогах, исключённых из production export. При последующем согласованном внедрении принятые ресурсы перенесены в `scenes/vfx/`, `resources/vfx/`, `assets/vfx/`; исходный debug avatar теперь использует тот же компонент энергии, что и TowerVisual. Изменения внедрения описаны в отдельном отчёте.

Превью: `scenes/debug/TowerEnergyPreview.tscn`. Отдельный avatar объединяет существующий TowerVisual с эффектом. Эффект следует положению кристалла; центральная точка визуала находится выше его существующего pivot.

Используются CPUParticles2D и CanvasItemMaterial с аддитивным смешиванием, без зависимости от renderer glow. Всплеск запускается бесплатным GFFParticles/GFFPlayer. Частые тапы не создают более одного активного burst emitter на образец; после 0,82 с он освобождается.

Dev Web экспортирован через Godot MCP пресетом Web Game Feel Pilot с переопределённым выходом `build/web/preview/tower-energy/index.html`. Главная сцена после экспорта восстановлена в main_menu.tscn. Обычная браузерная сборка не пересобиралась для добавления этого эффекта.

## Проверки

- MCP lint: 65 сцен, 82 скрипта, 0 ошибок/предупреждений.
- Native Godot: превью запущено, визуал просмотрен, runtime errors отсутствуют.
- Edge Web: запуск, touch-тап, повторные нажатия мышью, выключение/включение фонового свечения; консоль без ошибок.
- После 9 тапов число узлов вернулось с 46 к исходным 44; динамических burst emitters не осталось.
- Просмотрены браузерные скриншоты спокойного состояния и всплеска при размере 450×800. Touch проверен эмуляцией, физическое устройство не проверялось.

Визуальная проверка этого превью завершена; далее проверяется результат внедрения в настоящий бой. Commit и push ещё не выполнялись.
