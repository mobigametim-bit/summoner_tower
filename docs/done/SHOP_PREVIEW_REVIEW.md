# Магазин душ — превью интерфейса и иконок

18.10.2026. Превью принято пользователем с последними правками меню; разрешена
игровая интеграция. Ниже сохранён отчёт именно о HTML/SVG-превью.
Реализация в Godot: [SHOP_GAMEPLAY_REVIEW.md](SHOP_GAMEPLAY_REVIEW.md).

## Предложение для игрока

- По правке пользователя вход — отдельная кнопка с собственной иконкой лавки между
  улучшениями и настройками. Размер совпадает с остальными кнопками; кошелёк
  снова только показывает баланс, плюс убран. В портрете четыре кнопки в ряд,
  в горизонтальных форматах — в правом столбце.
- Отдельный экран с балансом и кнопкой назад.
- По правке пользователя количество кристаллов в каждом паке утроено:
  300 / 990 / 1800 / 3900 / 10500 за 99 / 299 / 499 / 999 / 2490 рублей.
  Это текущий согласованный состав превью; реальные товары площадки ещё не настроены.
- Цветовые рамки зелёная / оранжевая / красная / синяя / фиолетовая помогают
  различать размер паков. Все кристаллы сохраняют фиолетовый цвет валюты;
  товары не случайные, количество фиксировано.
- Постоянная покупка «Без рекламы» по решению пользователя стоит 299 рублей. В подробностях
  перечислены все три согласованные награды и ограничения: +50 ОЗ один раз за
  забег, пересброс один раз за боссовую волну, ×2 один раз в результатах.
- Иконки вместо длинных подписей там, где смысл сохраняется; для состава и лимитов
  оставлены короткие пояснения. Текущие фон, золотые кнопки и шрифт Itim-KZ.

## Границы и проверки

Макет не читает и не пишет игровые сохранения, не вызывает оплату, не подключает
SDK и не начисляет валюту. Демонстрационный баланс фиксирован — 248.
Кнопки цен открывают состав товара; «Понятно», крестик и Escape закрывают описание.
Доступны кнопка назад, вход из меню, переключение форматов. Фокус удерживается
в открытом диалоге и возвращается к выбранному товару после закрытия.

Проверено в Edge/Playwright: все ресурсы и шрифт загружаются, browser pageerror
и ошибки HTTP отсутствуют. В каждом из трёх форматов шесть карточек помещаются
без переполнения; описания малого пака и «Без рекламы» полностью видны.
После визуальной проверки горизонтальное описание «Без рекламы» уплотнено:
три награды в ряд, кнопка закрытия читаема и доступна без прокрутки.
В исходной версии проверялись вход через плюс и кошелёк, возврат назад, Escape
и удержание Tab в диалоге; вход заменён кнопкой лавки по последующему решению.
В отдельном контексте 390×844 с эмуляцией touch реальными tap-событиями открыты
и закрыты описание и меню. Баланс остался 248; localStorage/sessionStorage пусты.
Исходные шесть SVG разбираются как XML, ссылки на снимки и документы существуют.
После правок пользователя повторно проверены все три формата: кнопки меню одного
размера (69/64/100 px), лавка третья между улучшениями и настройками, четыре кнопки
помещаются в экран. Вход работает, плюс и действие кошелька удалены. Проверены
300/990/1800/3900/10500 в каталоге и карточках, цена «Без рекламы» 299 рублей,
отсутствие переполнения и HTTP/browser errors. Девять снимков обновлены;
визуально просмотрены исправленные мешочек, портретное меню и горизонтальное меню.
В следующей правке планшетного меню кошелёк центрирован относительно правого
столбца кнопок. Кристалл увеличен с 30×35 до 60×70 px, цифры — с 34 до 68 px.
Целевая проверка Edge подтверждает совпадение горизонтальных центров, отсутствие
обрезки и пересечения с кнопками; вход в магазин работает. Снимок menu-tablet.png обновлён.
По следующей правке кошелёк планшетного меню поднят на одну горизонталь с названием
биома, сохранив двойной размер и центрирование над кнопками. Совпадение вертикальных
центров заголовка/кошелька и горизонтальных центров кошелька/кнопок проверено в Edge;
menu-tablet.png обновлён.
Физические устройства здесь не проверялись.
Запуск Godot и повторный Web export для отдельного HTML-превью не требуются.

## Ручная проверка

1. Открыть превью и переключить телефон ↕ / телефон ↔ / планшет ↔.
2. Проверить размер иллюстраций, количества кристаллов, цены и удобство кнопок.
3. Открыть «Без рекламы», проверить понятность трёх наград и лимитов.
4. Открыть «Вход из меню», нажать лавку между улучшениями и настройками и вернуться назад.
5. Принять внешний вид либо дать правки; магазин в Godot подключается после приёмки.
