# Itim KZ — замена шрифта на ручную приёмку

18.10.2026. По просьбе пользователя интерфейс переключён с Tsap-Tsarap на
`assets/fonts/itim-kz/Itim-KZ-Regular.ttf`. Принято пользователем 18.10.2026.

[Проверить игру с новым шрифтом](http://127.0.0.1:4175/preview/itim-kz/).
Это локальная Web-сборка; публичный Pages пока не обновлён.

## Изменения

- Общий шрифт проекта и game_theme: Itim KZ Regular.
- Явные переопределения шрифта в BOSS, всплывающей награде маны и двух
  анимационных стендах также переключены на Itim KZ через Godot MCP.
- Надпись BOSS: кегль 220 вместо 260. Новый шрифт шире: BOSS/БОСС при 260
  занимали 649/668 px, при 220 помещаются в вертикальный экран с запасом.
- Длинные названия метаулучшений переносятся по словам; высота карточки 220
  вместо 172 логических px позволяет сохранить кегль, внутренние поля и цены.
- Загрузочный HTML использует Itim KZ. `tools/package_web.py` копирует шрифт,
  LICENSE.txt, COPYRIGHT.txt и OFL_39.txt в branding/ рядом с Web export.
  Исходные лицензионные файлы сохранены в папке шрифта.
- Старый шрифт сохранён для возможности отката. Статическая PNG-карточка
  пересылки ссылки не перерисовывалась.

## Проверки

- Godot MCP: проект Summoner Tower, 4.7.2, Compatibility, несохранённых сцен нет.
- FontFile сообщает семейство Itim KZ; все русские буквы, включая Ё/ё, латиница,
  цифры и используемые знаки процентов/математики присутствуют.
- Native: меню, настройки, метаулучшения RU/EN, послебоссовые карточки,
  экран итогов и HUD; runtime получает Itim KZ. Финальные runtime errors отсутствуют.
- Web release export через MCP, упаковка лицензий; загрузочный TTF отдаётся с HTTP200.
- Edge 390×844: меню, настройки, метаулучшения, длинные названия внизу списка,
  прокрутка касанием, вход в бой и HUD. Дополнительно широкое окно 1280×800.
  Кадры просмотрены; `build/itim-font-web-report.json`: passed=true, errors=[].
- Проверки выполнялись на отдельном тестовом прогрессе в Godot и в новом
  временном браузерном контексте. Прогресс игрока не сбрасывался.

Физический телефон не проверен. Повторные проверки боя и баланса не требовались:
изменены шрифты, упаковка загрузчика и размещение текста.

## Ручная приёмка

1. Сравнить читаемость русских букв и чисел в меню, настройках и HUD.
2. Прокрутить метаулучшения до «Знания способностей» и «Расширенного выбора»:
   проверить переносы названий и видимость цены.
3. Оценить послебоссовые карточки и экран итогов при игровом масштабе.

Замена принята, отчёт перенесён в docs/done. Изменения сохраняются отдельным commit/push.
