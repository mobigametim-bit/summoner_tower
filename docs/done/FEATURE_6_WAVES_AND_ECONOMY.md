# Фича 6 — Волны и экономика забега

Статус: принята пользователем 05.10.2026.

## Результат для игрока

Враги выходят группами. За убийство начисляется мана, которую можно потратить
на новые призывы и продолжить merge. После завершения группы начинается
трёхсекундный перерыв, затем следующая волна. Призыв, перенос, swap и merge
доступны во время перерыва. HUD показывает номер волны, число оставшихся врагов
(включая ещё не появившихся) либо обратный отсчёт до следующей волны.

## Согласованный баланс

| Параметр | Значение |
| --- | --- |
| Первая волна | 4 врага, по 30 HP |
| Рост количества | +1 враг за волну |
| Рост здоровья | +5 HP за волну |
| Интервал появления | 1 s; первый враг сразу |
| Перерыв между волнами | 3 s |
| Награда за убийство | 3 маны |
| Враг достиг башни | 20 урона башне, 0 маны |
| Скорость врага | 160, без роста |
| Башня / стартовая мана | 100 HP / 100 маны |
| Цена призыва | 20, затем +5 за успешный призыв |
| Archer Lv1 / Lv2 / Lv3 | 10 / 22 / 50 урона; зелёный / оранжевый / красный |

Для волны `n`: количество `4 + (n − 1)`, HP `30 + 5 × (n − 1)`.
Например, десятая волна содержит 13 врагов по 75 HP. Параметры волн находятся
в `resources/balance/wave_config.tres`, базовые HP, скорость и урон врага —
в существующем `first_encounter.tres`. Характеристики Archer не изменены.
Новые типы врагов и Boss Wave относятся к фиче 8; здесь один прежний тип врага.

## Реализация

- `WaveManager` владеет спавном, списком активных врагов и двумя однократными
  таймерами. Состояния: `FIGHTING`, `INTERMISSION`, `STOPPED`. Волна заканчивается,
  когда закончилась очередь спавна и разрешены все активные враги, включая
  достигших башни. Перерыв также идёт при отсутствии существ на поле.
- Враг удаляется из учёта до отправки события награды или урона. Повторные
  события смерти, достижения башни и обратные вызовы из сигналов не дают
  повторной маны, урона или завершения волны. Повторный `start` и преждевременные
  либо повторные timeout не запускают дополнительную волну.
- `GameManager` передаёт награду в `SummonManager.add_mana`, а урон — башне.
  UI только отображает состояние. HP новой волны задаются экземпляру врага,
  общий Resource базовых характеристик не изменяется.
- Game Over останавливает оба таймера, врагов, атаки и управление, удаляет
  врагов и стрелы. Поздние callbacks не меняют волну или ману. Restart создаёт
  свежий забег: волна 1, 100 маны, цена 20, 100 HP, пустые шесть слотов.
- Постоянные узлы `WaveManager`, таймеры, HUD и сигналы сохранены в `game.tscn`
  через Godot MCP; UID существующих сцен и ресурсов сохранены.
- Web preset исключает `art/references/*`: пользовательские изображения
  референсов не используются игрой и не должны увеличивать экспорт. Сами
  изображения не изменены. Тестовые сцены и скрипты исключены из обычной сборки.

не проверялись. FPS в браузере на этой машине около 144; это не оценка

## Ручная приёмка

Обычная Web-сборка: `http://127.0.0.1:4175/`. Также можно запустить проект в Godot.

1. PLAY → сразу три раза SUMMON: мана 100 → 80 → 55 → 25. После четырёх убийств
   первой волны должно быть 37 маны, башня 100 HP, отсчёт 3 → 2 → 1.
2. Во время перерыва призвать четвёртого Archer, объединить две пары зелёных
   в оранжевых, затем оранжевых в красного. Следующая волна начинается один раз.
3. Продолжать Summon + Merge минимум до конца волны 10. Проверить рост числа
   врагов и HP, +3 маны за каждое убийство и доступность управления в перерывах.
4. Начать новый забег и не призывать: первый Game Over на волне 2,
   без наград за дошедших врагов. После Game Over спавн и атаки прекращаются.
5. RESTART: волна 1, 100 маны, цена 20, 100 HP, пустые слоты.
   MENU → PLAY также начинает свежий забег.
6. Проверить перетаскивание мышью либо touch во время боя и начисления маны:
   перенос, merge, отпускание вне слота и отмена сохраняют корректное поле.

Приёмка подтверждена пользователем. Отчёт перенесён в `docs/done/`, ссылка в плане
обновлена; изменения фичи оформляются отдельным commit и отправляются в `origin`.
