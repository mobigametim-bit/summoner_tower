# Фича 14.6 — предупреждение о боссовой волне

09.10.2026. Превью принято, интеграция реализована и проверена. Отчёт перенесён в `docs/done/` по указанию пользователя.

## Результат

Согласованная большая надпись BOSS показывается по центру один раз в начале каждой боссовой волны, пульсирует красный → белый → красный и исчезает через 1,8 секунды. Бой продолжается, надпись не перехватывает ввод. Дополнительных эффектов портала не добавлено.

Сцена `scenes/ui/BossWarning.tscn` добавлена в `Interface/Hud/BossWarning` через Godot MCP. `GameHud.update_wave()` использует существующий `WaveManager.state_changed` и запоминает номер уже объявленной боссовой волны. Обновления счётчика при спавне/убийствах не перезапускают эффект. Новая боссовая волна запускает его снова. При выходе из боя, выборе улучшения и открытии настроек предупреждение скрывается; продолжение той же волны не вызывает повтор. Новый забег создаёт новый HUD и сбрасывает отметку.

Четырёхсекундный Timer остаётся исключительно в `scenes/debug/BossWarningPreview.tscn`. В настоящем HUD циклического таймера нет. Волны, баланс, награды и сохранения не изменены.

## Проверки

- Godot MCP, 4.7.2/Compatibility: импорт и lint — 84 сцены, 94 скрипта, ошибок/предупреждений нет.
- Native: реальные начала волн 5 и 10 запускают эффект; дополнительные события `state_changed` сохраняют текущий кадр. После анимации надпись остаётся скрытой, в том числе спустя 4 секунды. Остановка волны скрывает её. Runtime errors отсутствуют.
- Web/Edge: настоящая волна 5 в development gameplay fixture `boss_warning_test=1`, однократный запуск, автоматическое скрытие, наблюдение дольше 4 секунд без повторения. Открытие настроек через touch скрывает надпись, продолжение боя не запускает её снова. Ошибка чтения времени остановленной анимации в диагностике fixture исправлена; повторная проверка прошла без ошибок browser console.
- Production Web export обновлён; главное меню и запуск игры проверены. Development fixture использует отдельное тестовое сохранение и исключена из production.
- `git diff --check` проходит. Длительный прогон баланса и нагрузочный прогон не повторялись: изменено только предупреждение в HUD.
