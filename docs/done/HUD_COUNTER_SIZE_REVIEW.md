# Увеличение здоровья и маны в нижнем HUD

18.10.2026. По просьбе пользователя увеличены цифры и иконки двух счётчиков.
Принято пользователем 18.10.2026.

[Проверить в браузере](http://127.0.0.1:4175/preview/hud-counters/).

- Обычный кегль: 64 вместо 48 (+33%). Крупные суммы автоматически уменьшаются
  до подходящего размера, нижний предел 40 вместо 36.
- Сердце: 54×54 вместо 40×40; огонь маны: 54×65 вместо 40×48 (около +35%).
- Поля цифр расширены до 112 px. Уплотнены промежутки, увеличено место для
  подписи волны; счётчики остаются в одной строке, шестерёнка сохраняет размер 104×104.
- Изменены только HUD в game.tscn (через Godot MCP) и подбор кегля в game_hud.gd.
  Баланс, начисление валюты и размеры игрового поля сохраняются.

Godot 4.7.2 Compatibility: реальный game.tscn запущен через MCP на изолированном
прогрессе, runtime errors отсутствуют. Проверены 0/100/999/1.25K/9.99M/999T:
текст помещается в поле; русская подпись «ВОЛНА 24» также помещается.
Web release export и упаковка выполнены. Edge 390×844 и 1280×800: кадры просмотрены,
настройки открываются касанием шестерёнки, продолжение работает.
`build/hud-counters-web-report.json`: passed=true, errors=[].

Физический телефон не проверен; публичный Pages этой правкой пока не обновлён.
Для ручной приёмки: оценить размер сердца/маны и цифр, расстояния в строке,
проверить пополнение/расход маны и доступность шестерёнки.
