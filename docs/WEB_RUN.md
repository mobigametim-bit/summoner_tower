## Локальная сборка

Окружение: Godot 4.7.2, Compatibility, export templates `4.7.2.stable`, однопоточный Web. Preset `Web` в `export_presets.cfg`; основной экран — `scenes/main_menu.tscn`. Версия редактора и успешный release export подтверждены через Godot MCP 11.10.2026.

Экспорт через подключённый MCP: `export.build` с `preset: "Web"`, `debug: false`. Эквивалентная команда из PowerShell:

```powershell
& 'C:\Gamedis\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe' --headless --path 'C:\Gamedis\summoner-tower' --export-release 'Web' 'build/web/index.html'
python tools/package_web.py build/web
```

Локальный HTTP-сервер из корня проекта:

```powershell
python -m http.server 4175 --bind 127.0.0.1 --directory build/web
```

Сейчас сервер уже запущен в фоне. Основная игра: [http://127.0.0.1:4175/](http://127.0.0.1:4175/). Содержимое `build/web/` открывать через HTTP, не через `file://`.

HTTP работает для loopback (`127.0.0.1`/`localhost`), который браузер считает безопасным контекстом. Текущий загрузчик Godot требует secure context; для доступа с телефона по сетевому IP нужен HTTPS. Временная публичная ссылка через установленный Cloudflare Tunnel создаётся командой `cloudflared tunnel --url http://127.0.0.1:4175`; доступ существует, пока процесс работает. Самостоятельно туннель не запускался.

Для размещения передавать основные файлы `index.*` вместе с упакованной папкой `branding/`; вложенная папка `preview/` содержит служебные проверки и не входит в комплект игры. Основной `Web` preset исключает debug-сцены, debug-скрипты, тесты, документацию и исходные референсы. Сборки и локальные профили браузера исключены из Git разработки. Оформление ссылки: [исходники и сборка](../web/branding/README.md).

Браузер запускает аудио после первого клика/тапа/клавиши. Начальная громкость музыки 10%, звуков 60%; уже сохранённые настройки имеют приоритет. Прогресс и настройки записываются через Godot `user://` в IndexedDB. Текущий забег не сохраняется. Для повторного доступа к тем же браузерным данным сохранять origin: протокол, host и порт.
