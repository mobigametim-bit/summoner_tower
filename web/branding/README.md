# Иконка и превью ссылки

- `assets/branding/app_icon.svg` — иконка 512×512, собранная из существующего SVG башни.
- `assets/branding/boot_splash.png` — её PNG-копия для загрузочного экрана Godot; splash поддерживает PNG.
- `preview.html` — исходная композиция карточки: существующие SVG башни, Archer, Frost Mage и окружения.
- `og-image-v1.png` — готовая карточка 1200×630; `app-icon-v1.png` — готовая иконка 512×512.

PNG получены рендерингом SVG/HTML в браузере, без генерации изображений.
`web/.gdignore` исключает эти служебные файлы и дубликаты изображений из игрового PCK.

Перерисовка PNG из исходников: `node tools/render_web_branding.cjs`.
Нужны Playwright и установленный Microsoft Edge. Если Playwright находится вне стандартного
`node_modules`, указать абсолютный путь к модулю в `SUMMONER_PLAYWRIGHT`.
Скрипт также обновляет PNG загрузочного экрана.

После Web export выполнить `python tools/package_web.py build/web` (или передать другую папку экспорта).
В публикацию копировать `index.*` и папку `branding/` из упакованного экспорта.
HTML-исходник и этот README публиковать не нужно.

OG/Twitter-метаданные хранятся в `html/head_include` основного preset `Web` в `export_presets.cfg`.
При смене адреса сайта обновить абсолютные URLs в этой настройке.
При замене карточки использовать новое имя изображения и обновить ссылки в метаданных;
мессенджеры могут сохранять старую карточку в своём кеше.

## Анимированный загрузочный экран

`web/loading.html` — Custom HTML Shell основного preset `Web`, основанный на шаблоне
установленного Godot 4.7.2. Сохраняет стандартный запуск движка, прогресс и обработку ошибок.
Название игры использует `$GODOT_PROJECT_NAME`, метаданные — `$GODOT_HEAD_INCLUDE`.
Башня встроена как SVG из собственной иконки; кристалл и ореол анимируются CSS.
Размер — `50vmin`, половина прежнего splash, заполнявшего короткую сторону экрана.
После старта игры загрузочный DOM удаляется вместе с анимациями.

`package_web.py` дополнительно копирует используемый загрузчиком шрифт Tsap-Tsarap и его
`readme_216.txt` в папку `branding/`. Собственные HTML/CSS и готовые картинки находятся вне PCK.
После изменения загрузчика нужен Web export и упаковка. Native splash по-прежнему статический.
