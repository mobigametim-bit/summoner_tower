# Маски частиц Kenney

Автор: Kenney (Kenney.nl). Набор **Particle Pack**, лицензия **CC0**.

- Страница: https://kenney.nl/assets/particle-pack
- Архив: https://kenney.nl/media/pages/assets/particle-pack/f8fe0f8cb8-1677578741/kenney_particle-pack.zip
- Дата получения: 17.10.2026.
- Исходная лицензия из архива сохранена в `LICENSE.txt`.

Использованы прозрачные PNG: `light_01`, `light_02`, `magic_05`, `smoke_04`, `twirl_01`, `spark_02`.
Уменьшены с 512×512 до 128×128 для мобильного Web. Цвет и движение задаются в Godot.
Пресеты Unity, шейдеры и сторонние скрипты не используются.

Изучен также Cartoon FX Remaster Free (Unity Asset Store, JM Jean Moreno); в проект не импортирован.
